# PDF 全能处理

处理 PDF 时最烦的不是「读不出来」，而是每种操作都要换一套工具。这个技能把常见操作收在一处，模型知道该用哪个库、该怎么写。

## 适合用它的时候

- 用户丢来一份 PDF，要**抽取正文、表格或图片**
- 要把多份 PDF **合并**，或按页**拆分**成单页文件
- 扫描件需要 **OCR** 转成可检索文本
- 需要**填写 PDF 表单**（这是它有独立工作流文档的部分，不是硬猜坐标）
- 加水印、加解密、旋转页面这类机械操作

## 装了之后大概怎么用

直接说需求即可，例如「把这份 PDF 的第 3-8 页拆出来」「把这个表格导成 xlsx」。技能会引导模型选用 pypdf / pdfplumber / reportlab 或命令行工具，并给出可运行的代码。

## 注意

扫描件 OCR 依赖系统里的 tesseract 与 poppler，沙箱镜像不一定自带，第一次用到时可能需要先装依赖。
