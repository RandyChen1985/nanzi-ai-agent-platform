# Excel 表格处理

判断要不要用这个技能很简单：**本次任务的输入或产出是不是一个表格文件**。是，就用它。

## 适合用它的时候

- 读取、修改已有的 xlsx / xlsm / csv，例如加列、改公式、套格式
- 从零生成一份表格，或从其它数据源整理成表格
- 清洗脏数据：错位的表头、夹杂的合计行、类型混乱的列
- 把数据做成图表页

## 不适合的时候

最终交付物是 Word 文档、HTML 报告、一段脚本或数据库管道——即使中间有表格数据，也不该用这个技能。

## 装了之后大概怎么用

说清楚「哪个文件、改哪列、要什么结果」即可。它会把公式真正写进单元格并校验计算结果，而不是只写个看起来像公式的字符串。
