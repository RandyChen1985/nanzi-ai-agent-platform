# Web 应用测试

前端问题的特点是「说得清、看不见」。这个技能用 Playwright 把「看见」这一步补上。

## 适合用它的时候

- 验证本地起的前端页面：关键流程能不能走通
- 复现并定位 UI 问题：点不到、状态不对、报错在哪
- 需要**截图存证**给用户看
- 抓浏览器 console 报错与失败的网络请求

## 装了之后大概怎么用

给它地址和要验证的路径，例如「起在 5173，验证登录→下单→支付跳转」。它会驱动浏览器点击、断言页面状态、把截图和控制台输出带回来。

## 注意

沙箱里要能访问到页面（本地服务需监听 0.0.0.0 或容器可达地址），否则 Playwright 连不上。
