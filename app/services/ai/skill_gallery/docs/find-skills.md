# 技能发现器

平台内置的技能广场是**我们审过的那一小撮**。真正的长尾需求（冷门 API、特定框架、某家公司的内部工具）没法都收进来——这时让智能体自己去搜。

## 适合用它的时候

- 用户问「有没有技能能处理 X」「找个工具帮我做 Y」
- 手上有个重复性流程，想看看社区里是不是已经有人写好了
- 需要扩展能力，但不知道从哪儿下手

## 它怎么工作

把需求转成检索词 → 在技能目录里搜 → 给出候选并说明差异 → 用户点头后安装到当前工作目录。装了之后技能文件就在 `.agents/skills/<id>/`，可以直接用 `import_skill_from_sandbox` 收进平台技能库。

## 注意

搜到的技能是**第三方代码**，装上就会以完整智能体权限运行。装之前让它先说清这个技能会做什么、来自哪个仓库。
