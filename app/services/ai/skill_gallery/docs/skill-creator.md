# 技能创作助手

写技能最容易犯的错是：写了一堆模型永远想不起来看的内容。

## 适合用它的时候

- 要把团队里一套固定流程沉淀成技能
- 已经写了 SKILL.md，但模型「该调用时不调用」
- 不确定什么内容该放正文、什么该拆到 scripts/ 或 references/

## 它会帮你判断

- frontmatter 的 `name` / `description` 该怎么写才有触发力
- 正文该用「祈使句指令」而不是「说明书语气」
- 什么时候必须配 `scripts/`（流程里有确定性计算），什么时候只写正文就够
- 技能边界：一个技能只做一件事，别写成瑞士军刀

## 装了之后大概怎么用

先描述流程本身（谁在什么场景下做什么），让它反推技能结构；比直接说「帮我写个技能」有效。
