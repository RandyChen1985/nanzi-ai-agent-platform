# 浏览器操作员

很多任务卡在「页面上有什么」这一步：数据是 JS 渲染的、接口要先登录、按钮点下去才出现下一个字段。

## 适合用它的时候

- 需要打开某个网站，按步骤操作（登录 → 搜索 → 导出）
- 抓取渲染后才有的内容（静态 HTML 里没有）
- 验证刚起的 Web 应用能不能走通
- 截图留证

## 和 webapp-testing 的区别

`webapp-testing` 偏**测自己的应用**（Playwright 断言 + 回归）；这个偏**操作别人的网站**（导航、填表、抓数据）。两者都能截图，选哪个看目的是"验证"还是"代办"。

## 注意

沙箱里要先有可用浏览器（Chromium），第一次用到时可能要装依赖。需要登录的站点还得先解决凭据怎么给。
