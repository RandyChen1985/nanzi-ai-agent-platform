# 任务表单「两栏指令」填写引导改造（方案 B）

**需求（用户原话）：** 附截图圈出「执行指令 (PROMPT)」与「任务约束指令」，说「这两个指令不够清晰，用户不知道怎么填，看看怎么优化一下」。
**选型：** 三套方案（A 只改文案 / B 文案+引导结构 / C 合并单框 AI 拆分）已做原型对照，用户选定 **方案 B 完整版**（含两处此前定案为「不做」的新交互，见第 6 节）。

## 2. 目标与非目标

**目标**：让用户在不点任何帮助入口的前提下，从标签 + 提示条 + 占位符三处就能判断「这段内容该写在哪个框」。

**非目标**：
- 不改后端：`config.task_constraints` 字段名、调度器 `_build_scheduled_task_prompt`、system 段标签（`【📋 任务执行指令 - ID: x】`）全部不动；
- 不改数据结构、不加迁移；
- 不做历史任务批量迁移（只做「写下时」的实时提示 + 一键搬移）。

## 4. 「位置纠偏」交互契约

- **触发**：`editingTask.prompt` 按 `\n。；;` 切句后，第一句命中格式类正则即提示；只展示一句，句子消失则提示自动收起。
- **正则**（宁可漏报不可乱报，`图表` / `表格` 单独出现**不**命中）：

```
((不要|禁止|不允许|别|勿)[^。；;\n]{0,10}(图表|表格|画图|echart|代码块|寒暄|反问|废话|过程说明|猜测|臆测))
|((用|按|以|改成)[^。；;\n]{0,6}(无序列表|列表|纯文本|移动端)[^。；;\n]{0,6}(呈现|输出|排版|分行|展示))
|((单位|金额)[^。；;\n]{0,6}(统一|一律))
|(保留[一二两三四0-9]{1,2}位小数)
```

- **`移到第 2 栏`**：把该句从第 1 栏删除、追加进第 2 栏（拼接口径与预设 chips 一致：去尾标点 + `；` + 新句 + `。`），随后 toast 提示。
- **`忽略`**：仅隐藏当前这一句的提示（记录 `dismissedAdviceSentence`），内容变了会重新评估，不写入任何持久状态。

## 5. 组件与数据流

- 只改两个前端文件：`frontend/src/views/TaskCenter.vue`（表单区 + 两个帮助弹窗）、`frontend/src/components/task/TaskPromptComposer.vue`（仅占位符；该组件全仓仅 TaskCenter 使用，已确认）。
- 新增状态：`constraintPresets`（常量）、`dismissedAdviceSentence`（ref）、`promptFormatAdviceSentence`（computed）、`moveAdviceToConstraints()`、`appendConstraintPreset()`。
- `taskConstraints` 仍是表单里的唯一真源，保存链路（`config.task_constraints`、`maxlength=2000`、后端超长拒绝）不变。

## 6. 与既有定案的关系（需记录的重启项）

`docs/superpowers/specs/2026-10-12-task-prompt-system-priority-design.md:319` / `:322` 曾把两项定为**不做**，本次经用户确认重启，范围收窄：

| 原定案 | 原理由 | 本次范围 | 明确不做 |
| --- | --- | --- | --- |
| 老任务约束迁移辅助 | 「改为由前端文案引导即可」 | 仅**键入时**实时提示 + 单句一键搬移 | 不做历史任务扫描、不做保存时批量搬移、不做提示弹窗打断 |
| 约束模板下拉 | 「与帮助弹窗示例卡片重复」 | 改为**框内一键追加**的常驻 chips，不开弹窗 | 不做下拉菜单、不做多选批量、不做服务端模板管理 |

## 7. 测试计划
