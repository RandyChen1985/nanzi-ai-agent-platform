## 1. 目标与约束

用户在凭据中心保存单值或结构化凭据，工具按类型和字段映射由服务端注入。模型只看业务参数和必要的账号选择元数据；实际凭据载荷不进入模型入参、公开工具参数、等待快照或完整出站日志。MCP 上游业务结果由用户配置的 JSONPath 决定可见范围：选中什么，就原样返回什么。

- Python 3.11、FastAPI、SQLAlchemy 2.x、AgentScope 2.x；前端使用现有 Vue 3/TypeScript 工程。
- 沿用当前凭据存储、归属/共享授权、类型版本、场景、域名、有效期及平台/个人策略。账号提示和绑定引用不授予权限。
- 已接入 MCP 视作用户已知且受信任的工具；本轮不新增远端信任审批，不采用 MCP Elicitation。
- 只生成代码、文档、原型和迁移文件，不直接修改真实数据库；服务启停与部署由用户在控制台执行。
- 原型仅存放在 `prototypes/`，CSS/JS 内联、无外部资源，一项需求一个 HTML，并通过 `python prototypes/build_index.py` 登记。

## 2. 凭据中心、类型与配置

兼容旧单值凭据和变量，存量记录保持 `legacy` 格式，不自动解密或合并。结构化实例记录类型键、发布版本、账号、加密载荷、值版本及必要公开元数据；轮换保持凭据引用，每次执行读取最新载荷。实例保留其创建时的类型版本，发布新版本不静默改写旧实例。

管理员可管理内置与自定义类型，通过可视化字段编辑器配置 JSON Schema 并预览录入表单。支持字符串、数字、布尔、枚举及对应校验，后端按已发布版本再次验证。敏感字段采用遮罩输入，表单值直达凭据 API。类型启用状态控制创建入口；凭据启停、过期、归属和授权控制实际使用。

系统配置使用 `structured_credentials_enabled` 和 `credential_payload_keyring_json`。沿用已确认的主库明文配置行为；首次保存前兼容既有部署配置。本次不重设计密钥存储。`structured_credentials_enabled` 只控制结构化凭据实例的新建；关闭后已有凭据仍可使用、轮换、编辑资料及重新绑定，类型定义仍可创建和发布版本。单值凭据、变量不受此开关影响。

类型自身的 `enabled` 与有效创建状态 `can_create` 分开：结构化类型须同时满足类型启用与全局允许新建，单值凭据、变量只检查类型自身状态。列表和创建选项按有效状态显示“已禁用（不可新建）”及原因，禁用的类型仍可查看字段、历史版本、JSON Schema 与表单预览。全局开关不批量改写类型状态；重新开启后仍保留管理员原先手动禁用的类型。

个人、管理员及原生补录创建共用后端创建检查，关闭前已打开的表单在关闭后提交也应拒绝。保留请求级配置检查，不将关闭操作设计为取消已经通过检查的在途事务。聊天和定时任务补录卡仍可选择已有凭据，类型信息可读，但禁止新建并说明原因。有效密钥环校验与创建开关独立；实例停用、过期、撤权、字段或映射失效、缺少解密密钥等仍按原规则拒绝，不因允许存量使用而放宽。类型内容可见不改变凭据明文不可读规则。

### 密钥生成、首次配置与轮换

系统配置的密钥环输入旁提供可展开的生成帮助。密钥由管理员在自己的可信本地终端安全随机生成 **32 个原始字节**，再做 URL-safe Base64 编码；不是 32 个字符，也不能使用口令或固定演示值。当前后端要求编码结果为 44 个字符、末尾保留一个 `=`。帮助提供以下可复制的 Python 命令，页面不执行命令或生成真实密钥：

```bash
python -c "import base64,secrets; print(base64.urlsafe_b64encode(secrets.token_bytes(32)).decode())"
```

首次配置示例（替换占位内容后提交）：

```json
{"active_key_id":"cred-v1","keys":{"cred-v1":"<替换为本地生成的密钥>"}}
```

轮换时重新执行命令生成另一把密钥，使用新编号：

```json
{"active_key_id":"cred-v2","keys":{"cred-v2":"<替换为另行生成的新密钥>"}}
```

JSON 顶层只含 `active_key_id` 和 `keys`；`keys` 为对象，活跃编号必须存在于其中。所有编号为 1–48 个英文字母、数字、下划线或连字符（`[A-Za-z0-9_-]`）。保存轮换配置时，服务端自动保留可解码的旧读密钥；不需要重新粘贴旧密钥，也不能用旧编号替换其原密钥。新建及实例轮换使用活跃密钥，旧密文继续按旧编号解密，切换活跃编号不会批量重加密已有实例。

页面留空表示不提交密钥环变更，保留现有配置；留空不会生成或清除密钥。未配置或配置无效时，仅打开总开关不能启用成功。接口中省略密钥环字段或传 `null` 表示不更新，显式空字符串不是有效密钥环。保存成功后清空只写输入，仅显示状态及活跃编号。密钥环 JSON 仍以明文保存在平台主库，主库备份也包含这些值。

帮助可复制命令及占位 JSON，复制失败时给出手动选择复制的反馈；复制内容不能自动写入密钥环输入。原型只演示格式校验和页面状态，不读取旧密钥、不调用真实配置接口。

### 使用范围与发现

个人和系统凭据均沿用现有使用范围。系统凭据统一以凭据中心的共享授权为依据（用户、部门或全体用户，包含授权有效期），不再叠加逐工具凭据使用授权。仍需通过工具访问权限、类型及版本、实例启停/有效期、场景和目标域名检查；管理员保存绑定不等于授予共享权限。凭据详情将固定绑定、按类型可用的动态工具及成功使用历史取并集，去重并标明来源；关闭结构化新建开关不隐藏已有凭据的动态适用工具。

候选发现、工具测试、固定绑定、实际注入、聊天及定时恢复采用同一共享授权口径，撤销或到期后的下一次查询/调用必须重新拒绝。已共享的结构化字段允许用户绑定到自己的 API、脚本及 MCP 认证槽位，个人绑定仍只对该用户生效；脚本双开关和目标摘要等限制保持不变。字段值仍由服务端解析和注入。

旧逐工具授权表保留为历史数据，不迁移为全局共享授权。旧 grants 接口仅保留带停用说明的历史查询和清理；新增授权返回明确的停用错误，使用权只在凭据中心维护。普通工具权限仍独立有效，不因凭据共享而自动获得工具访问权。

`list_my_credentials` 的个人/共享、单值/结构化统计保持完整，旧 `legacy_choices` 的 cN 编号范围和排序兼容；查询失败或能力关闭不能伪装为数量 0。

## 3. 模型投影、模式与候选发现

服务端分别维护真实 MCP 入参定义和模型入参投影。模型投影删除全部注入目标，以及 required/default/examples/description 中对这些字段的引用；保留未注入业务字段的原名、必要说明、枚举、数值约束和对象/数组结构。可能混有认证字段说明的远端根级描述改用本地类型与调用说明。

| 模式 | 模型可见内容 | 调用行为 |
| --- | --- | --- |
| fixed | 业务参数，不含 `credential_account` 或固定字段的选择编号 | 直接调用，服务端使用保存的引用并注入；失效进入修复/原生选择，不能静默换账号 |
| infer | 业务参数及可选字符串 `credential_account` | 先按当前挂载工具发现候选，再将账号提示交给服务端精确匹配 |
| ask | 业务参数，无模型账号字段 | 使用已有原生界面选择；保留旧配置兼容 |
| 逐参数固定/规则/混合 | 本地注入模式摘要及该策略真正需要的选择字段 | 按当前用户优先、同层规则优先解释绑定；固定字段不要求模型挑选编号 |

### 固定凭据的配置交互

“同一条凭据”表单切换为固定模式后，立即在“凭据选择方式”下方、字段映射上方显示“我的固定凭据”。候选按表单当前类型和版本读取，不要求先保存映射；仅列出当前用户本人或已共享、且符合该工具场景及目标域名的凭据元数据，系统凭据标明“系统共享”。不读取或展示字段值，不自动选择第一条。

已有有效固定绑定应回填；不可用的旧绑定保留引用并提示重新选择，用户明确选择其他凭据或留空前禁止保存，避免隐式解绑。更换类型或版本后重新加载候选并清除不兼容的选择，迟到响应不能覆盖新草稿。加载中、无可用候选和查询失败分别提示，失败允许重试，不能将查询失败显示成“没有凭据”。保留显式“未绑定”选项，说明未绑定时调用需要补充选择。

“保存设置”在一个事务内保存映射、结果字段及当前用户的固定引用，无须再点一次“保存绑定”。保存时重新校验凭据资格及配置版本；失败不得留下只保存映射而未保存所选绑定的中间状态。绑定只对当前用户生效；切换模式或类型导致的既有绑定失效规则保持不变。

管理候选接口支持可选的 `type_key`、`type_version` 草稿查询参数，两者须成对提供并校验配置管理权限与已发布类型版本；未提供参数仍按已保存配置查询。配置保存接口可选传入 `fixed_secret_id`：仅固定模式接受，字符串表示个人绑定，`null` 表示解除个人绑定；省略该字段的旧客户端沿用原保存行为。调用期固定模式仍不向模型提供 `credential_account`，不要求模型查询或选择凭据。

工具说明公开凭据中心来源、绑定类型名称/type_key/版本和正确调用方式。逐参数策略每次装载重新读取并投影，避免固定/规则切换后复用旧 schema。`health`、`health_check`、`healthcheck` 使用本地“服务健康检查”说明。注入模式摘要不保证凭据当前有效，出站前仍须校验。

例如 username/password/host/port 已映射、folder 未映射：infer 模型只见 folder 与 credential_account，fixed 模型只见 folder。模型不能通过额外属性或嵌套对象补回认证参数。

`list_mcp_credential_candidates` 只为当前运行时已挂载的 infer 工具查询候选。发现过程不解密 payload，只返回选择所需名称、账号、引用和类型信息，候选限执行用户本人或已经共享且符合工具类型/版本及使用权限的记录。

显式提供 `limit` 时，底层候选查询按 `(account, id)` 稳定分批读取，避免在权限过滤前全量缓冲，按权限过滤后的可用候选计数；未指定上限时保持单次查询的完整结果，不以隐含截断改变发现语义。

- 模型可利用当前消息、历史、邮件、网页、工具结果中的账号线索，不要求本轮用户原文逐字包含完整账号。
- 模型可将口语“alice”关联到真实候选的完整账号；后端规范化后精确匹配，不模糊挑选同名记录。
- 已挂载 fixed、规则或交互选择工具返回 `CREDENTIAL_CANDIDATES_NOT_REQUIRED`，提示直接调用；不能返回空候选造成“没有凭据”的误解。
- `CREDENTIAL_TOOL_NOT_AVAILABLE` 只表示该 MCP 当前未挂载；已声明 infer 但内部引用缺失属于配置变化。查询失败与真正零候选分别返回明确原因；关闭结构化新建开关不阻断已有候选查询。

| 匹配/运行情况 | 用户可见行为 |
| --- | --- |
| 账号唯一匹配且可用 | 自动继续，出站前重验权限 |
| 缺少选择、无法确定、多候选 | 原生选择卡，不任意选第一条 |
| 确认无匹配 | 允许新建时按绑定类型版本提供原生补录表单，否则显示禁止新建原因；仍可改选已有凭据 |
| 已有引用停用、过期、撤权 | 提示不可用并等待修复/重选 |
| 配置变化、密钥不可用、查询失败 | 受控错误，不误导用户重复创建 |

## 4. 原生录入、恢复与服务端注入

原生表单绑定 request、执行用户、会话/任务、工具、profile 版本及调用参数摘要；按绑定类型版本的 JSON Schema 渲染和验证。密码等字段直接提交凭据 API，不经聊天消息、模型工具参数或模型可读返回正文。只有实时检查确认为缺失且该类型允许新建时提供可提交的补录表单，取消/失效的旧卡不能继续创建或恢复。禁止新建时仍允许选择已有凭据并恢复当前调用，不把创建限制误报为无可用凭据。

“保存并继续”成功后只回传凭据引用和状态，恢复对应等待调用。恢复重新校验用户、类型、配置、授权、状态和参数摘要，使用持久化 claim 防止重复消费。用户在原生卡明确选择的引用优先于模型提示。fixed 正常免选择，失效后的修复或当次替代须由用户在原生界面明确选择。

实际出站顺序：

1. 校验主体、当前工具、profile 身份/版本和真实调用资格。
2. 按固定引用、可信任务引用或模型账号提示定位候选。
3. 读取授权通过的 payload，按其类型版本验证字段。
4. 新建独立出站对象，保留声明的业务参数，删除 credential_account 及模型伪造的注入目标。
5. 按映射赋值，例如 `username1 → username`、`password1 → password`、`host1 → host`、`port1 → port`。
6. 仅交给实际 MCP 传输层，不回写模型原始参数、事件或等待快照。

当前支持顶层字段映射及对象字段整体映射；缺字段、类型不匹配、目标 schema 变更时拒绝出站并提示修复。连接认证仅用于出站认证；API 工具沿用结构化字段到固定请求头/请求体的绑定。未声明的嵌套认证字段不透传。

## 5. MCP JSONPath 结果和记录

采用 RFC 9535 JSONPath，在解包后的原始业务 JSON 上求值；支持根节点 `$`、对象/数组/标量、负下标、联合、切片、递归、过滤及标准函数。MCP structured content、JSON 文本和完整响应外壳按现有规则解包。

| 配置/响应 | 预期 |
| --- | --- |
| `$` | 原样返回完整业务根值 |
| `$.messages[*].subject` | 保留选中的主题节点及其结构，其他未选字段不返回 |
| `$.messages[*][1]` | 保留每行第二列；局部数组投影按原下标以 null 占位 |
| `$.messages` 选中空数组 | 返回该空数组 |
| 空配置、非法表达式、无匹配或查询预算失败 | 返回 restricted 状态和可诊断原因，不放出原始响应 |

选中的字段和值原样返回，不按 token/password 等敏感字段名、不按凭据值精确回显、不按健康状态白名单做二次过滤。即使结果值与本次注入的合成凭据相同，选中后也按业务结果进入模型上下文、对话历史、执行追踪或定时任务结果。未选中内容不返回。

组凭据配置保存其结果策略；服务 Header、连接令牌或逐参数凭据也可保存工具级独立结果策略。参数来源与结果字段应一次保存，无输入参数工具同样可配置。测试台展示模型调用名、`result_visibility` 及 restricted 原因。配置变更仅影响后续调用。

输入注入和结果投影分开管理：不得将完整注入请求、凭据表单正文或临时 payload 写入聊天、HTTP 审计、异常、通用缓存、任务定义或等待快照；保留执行用户、工具、凭据引用、时间和状态等使用审计。由 JSONPath 主动选中的上游业务内容按上述结果规则记录，不能再次被输入隔离逻辑过滤。

正常、错误、超时、取消后清理本次注入上下文。受保护调用遇传输错误不自动重放，避免重复外部副作用。

## 6. 脚本环境变量：单值与结构化兼容

恢复已有固定 env 绑定。单值使用 `secret_id + script_tool + env:NAME`；结构化额外指定已发布类型版本中的标量 `value_field`，复用 `SecretBinding.value_field/target_digest`。不为脚本新增动态账号选择或规则绑定；遗留不支持的规则明确拒绝。

脚本通过 `os.environ` 读取变量，不向模型增加对应参数。变量名最多 124 字符，拒绝解释器/加载器等执行器保留变量和 NUL。数字、布尔值确定性转成环境字符串，不对对象隐式 repr。目标摘要包括脚本源码、依赖及参数 schema，相关变更后重新绑定。

执行用户仍需通过归属/共享、场景、有效期及平台 `secret_policy_allow_script_env` 与个人偏好双开关。管理员配置系统凭据的全局绑定入口保留；后端校验个人绑定所有者。一条结构化凭据映射多个变量按一条凭据计上限；解析失败、超过上限、字段失效或相邻字段跨越轮换时整次拒绝，不部分注入。

有凭据的脚本在每次新建的 Docker 容器或 K8s Pod 中执行，与模型通用 Bash 和共享工作目录隔开；不继承共享卷、原沙箱 env 或服务账号令牌。依赖安装阶段不接收凭据；凭据仅由后端内存经长度前缀 stdin 协议交给执行进程，不写公开参数、命令行、共享 .env 或全局 os.environ。惰性沙箱先准备提供者再解析凭据；local/e2b/ssh 不降级到宿主机。无凭据脚本保留原链路；现有容器策略下无会话试运行限制保留，凭据脚本保存后在智能体会话验证。

脚本输出具有独立的回显检查规则，不能将 MCP JSONPath 的“原样返回”外推为关闭脚本检查：stdout/stderr 在统一 ScriptRunResult 前检查本次凭据精确回显，覆盖短值、JSON 解码后的键和值及序列化文本，不保留首尾片段。完整 JSON 凭据或跨节点回显不能安全替换时隐藏整段。此规则保障平台注入和返回链路，不承诺防止可信脚本任意编码或主动外发。

输入快照上限 8 MiB/256 个普通非隐藏文件，从可信根目录 fd 打开并拒绝链接、越界，不复制 `.pylibs/.script_tools`。stdout/stderr 各 4 MiB 达限即终止，先检查后截断，返回最多 80 KiB/8 KiB。产物最多 8 个、每个 1 MiB，仅发布通过路径及内容检查的 UTF-8 文本；原始输出、未检查文件或含凭据产物不进入共享目录。成功、失败、超时和取消均清理私有执行实例。

前端恢复 `script_env` 场景，支持单值选择和结构化字段选择，保存/暂存/回显 value_field，只读取元数据；换选时防止旧请求覆盖新字段列表。界面说明“输出会检查凭据回显”，不承诺绝对零泄漏。

## 7. 定时任务与会话兼容

任务绑定真实执行用户，使用同一权限、候选和注入流程。用户在原生卡明确确认供任务复用后，仅保存 actor/task/tool/profile/version 与凭据引用；每次运行重验并读取最新 payload，轮换无需把新密码写入任务。

每工具保存一条默认引用；infer 本次明确给出 credential_account 时按该账号匹配，仅未提供账号时复用默认，支持同任务连续查询不同账号。ask/fixed 无模型账号字段，使用已确认引用。任务引用存于 config 服务端保留键，客户端不能创建/覆盖，公开响应隐藏；内部更新不改变任务定义摘要，并避免并发覆盖。

失效进入等待，恢复再验。执行用户、cron 等任务定义或配置变化及时使旧等待失效；恢复前重验任务存在、执行所有者及任务定义摘要，旧等待不得阻塞修改后的任务。恢复维持先任务后等待记录的加锁顺序，并保留已领取和已过期状态的判断优先级；并发恢复最多一次消费。已出站但响应丢失不自动重放。脚本任务也只存绑定引用，执行时即时解析 env。

会话 MCP 本轮挂载、工具清单、别名与候选查询范围保持一致。凭据关联统计和旧 cN 编号兼容均纳入验收。
