改了什么：
· 「?」从 28px 带边框圆按钮 → 16px 裸图标（text-gray-400），hover 才出现浅灰底和加深颜色；
· 「显示指引」从蓝底蓝框胶囊 → 灰字链接（text-gray-500），hover 变主题蓝。

为什么这样改：这两个都是低频辅助功能，但原来一个带边框、一个带品牌色，视觉权重和「发布审核」几乎一样，标题行看起来像摆了四个按钮。改成灰度 + 更小字号后，视线会先落在「智能体中心」和右侧主操作上，需要找说明的人才看得见它们。
颜色信息没丢——hover 时的反馈仍然存在，只是不常驻。
