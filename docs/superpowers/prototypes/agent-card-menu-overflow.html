根因不是菜单定位写错了，是卡片容器裁掉了它。
卡片根元素带 overflow-hidden（原本是为了让顶部色带跟着卡片圆角走），而菜单是 absolute bottom-full 向上展开、高约 240px； 按钮又在卡片底部，于是菜单上半截跑到卡片外面，被 overflow-hidden 直接裁掉——「预览对话」和「编辑智能体」正好在最上面。

改法：卡片根去掉 overflow-hidden，顶部色带自己加 rounded-t-xl。视觉上没有任何变化（色带仍然和卡片圆角吻合），但菜单能正常溢出显示。

「编辑智能体」没有丢。它一直在菜单里第二项，只是被裁掉了。裁掉之后看起来就像功能消失了，这也是这类 bug 最误导人的地方——入口还在，只是看不见。
