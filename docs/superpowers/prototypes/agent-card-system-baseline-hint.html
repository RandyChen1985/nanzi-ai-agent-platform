创建者 陈小龙 · 更新于 10/24 11:05 💬 ⋯ 配置与发布
为什么普通用户那句更长：他真正会误会的是这两件事 —— 以为「系统级」等于整份都不能碰（其实草稿照样能改），或者以为还能像以前一样点一下就上线（其实必须走审核）。一句话把能做的和不能做的都说清楚，比一个纯图标有用。

管理员那句就短：他不受这些限制，只需要知道「线上现在跑的是第几版」。

待审状态复用已有的冻结条（ 琥珀色），不叠加两条 —— 同一块地方只讲一件事：现在卡在审核。

版本号来自新字段 published_version_number，列表接口一次批量取，不额外查库。没有线上版本时显示「尚无线上版本」。
