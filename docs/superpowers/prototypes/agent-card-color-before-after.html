思路：一张卡只留一个颜色信号。
原来类型徽标按「通用/ChatBI/知识库」上三套色、能力 chips 又分五套色、就绪度还带彩框——四组颜色互相打架，眼睛找不到重点。
改后：类型、引擎、能力 chips、就绪度底色全部收敛成同一档浅灰（#f3f4f6 / #4b5563），去掉所有边框；
唯一保留颜色的是就绪状态前的小圆点——绿点=已就绪、琥珀点=待完善，需要扫一眼就知道「能不能用」时它最直接。
没动的：头像底色与卡片顶部色带（用于快速识别不同智能体）、底部主按钮、审核中的琥珀冻结条。
