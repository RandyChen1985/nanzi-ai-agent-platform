为什么按钮叫「申请上线」而不是「发布上线」：对所有者来说点了不会立刻生效，叫「发布」会让人以为已经上线了。

「发布上线」对所有者直接不出现（不是置灰），因为这条能力对他永久关闭，不是「暂时不可用」。

提交后立刻置为待审：按钮消失、出现「管理员审核中」，同时所有者被冻结——保证审的就是他提交的那一版。

审核队列用徽章区分两类申请：「转系统级」和「V3 上线」的处理后果完全不同，混在一起容易点错。
