兜底条的三条规则：
1. 只给工具类条目（鉴权、模型调用等不加，免得满屏在动）
2. 延迟 320ms 才出现——几十毫秒就结束的工具不会闪一下
3. 工具一结束就消失，历史回放里不会留下 100% 残影

不确定态的表现：一条两端淡出的光带 2.4 秒单向滑过一次，滑出后从左侧重新进入。 两端全透明，所以循环接缝看不出跳变；不用来回横跳，也不做亮度闪烁。
