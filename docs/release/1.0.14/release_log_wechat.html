🚀 核心更新亮点 (Key Features)

1. 🏗️ AI 编排责任链管道化重构与工程解耦

  • 6 阶责任链流水线：将原先单体庞大的 AgentService 解耦为 PreflightStep → ContextStep → RouteStep → AssembleStep → ExecutionStep → FinalizeStep，职责严格内聚，彻底清理冗余分支与死代码。
  • 分布式锁看门狗自动续约 (Watchdog)：引入后台守护协程，长任务与多轮推理期间自动为 Redis 会话锁续约，任务结束即刻释放，根除 409 会话忙与锁超时失效。
  • 长推理静默心跳与终态收敛：深度思考和工具等待期间自动下发 heartbeat 心跳，防止反向代理网关 SSE 断连；保证流式终态状态机必定收敛，告别前端死锁转圈。
  • 候选正文毫秒直出与首句工作区并发预热：首段文字以候选增量实时直出（TTFT 大幅缩短），触发工具时协议级 retraction 平滑转为过程引导；装配阶段异步并行初始化工作区与 Docker 沙箱，工具冷启动延迟归零；修复思考卡片防过早折叠。
  • 多工具并发异步调度：模型单轮次发出的无依赖工具调用由串行累加升级为异步并行执行（asyncio.gather），多源查数与检索耗时锐减 60%+，并设并发配额保护。
  • 工具证据分级响应门禁：三级事实置信度判定。工具查询失败或无数据时强约束模型事实防御，杜绝幻觉胡编；提供工具元查询与多级追溯 API。

2. 🌐 全功能平台 MCP 服务台与双向生态闭环

  • 平台全面开放为标准 MCP Server (入站)：外部应用（如 Cursor、Claude Desktop、VSCode 或自研系统）只需配置 NanZi 的 MCP 端点，即可直连调用平台内的通用智能体、ChatBI 数据查询、知识库检索与元数据工具。对外暴露的工具名统一规范为标准下划线风格。
  • 企业级 OAuth 2.0 与 Scope 版本控制： 构建完整的客户端凭据生成、OAuth 授权体系；支持 7天/30天/永久等自定义 Token 有效期；引入 scope_version，权限调整后旧 Token 自动失效防越权；支持全员共享 Client 协作。
  • 调用第三方 MCP 的用户身份上下文透传 (UserContext Assertion 核心特性)：
    • 解决的痛点：过去平台调用外部企业自研 MCP 工具时，只能配置全局统一的静态 Token。第三方系统无法知道是哪位具体员工在操作，无法落实数据行级权限控制、部门级权限隔离或精准操作审计；若将用户信息放在 Prompt 参数中，极易被模型遗漏或篡改。
    • 双轨分离认证协议：支持独立的 Authorization: Bearer（证明请求来自 NanZi 平台合法客户端）与 X-Nanzi-User-Assertion（携带当前真实用户身份凭证的 JWS 签名串），两者互不耦合、各自独立生效。
    • 防伪造非对称签名与密钥隔离：平台在后端为每个开启的第三方 MCP 独立生成非对称签名私钥（Ed25519/EdDSA）与专属 Audience，私钥在数据库高强度加密，绝不回显前端；第三方 MCP 服务仅需读取公钥验证签名。
    • 结构化 Payload 规范：JWS 签名载荷包含标准字段：主体 sub、user_context（真实用户 ID、用户名、姓名、部门代码、组织路径）、安全过滤后的扩展属性、发起调用的智能体信息（ID、版本、名称）以及防重放攻击的 jti 和 60 秒极短有效期（exp）。
    • 公钥发现与一键生成对接代码：平台对外暴露标准 JWKS 公钥发现端点（/.well-known/nanzi/mcp/{mcp_server_id}/jwks.json）；管理页面提供 Python / Java 双语言的一键生成验签中间件代码，开箱即用。
    • 内置 Echo 诊断测试服务：平台提供一键创建 Echo 测试 MCP 实例，可全链路模拟并回显 Bearer Token 与 UserContext 验签结果（user_assertion_received=true、user_assertion_valid=true），让开发者零成本排查 DNS rebinding、Header 传递与验签全流程。
  • 出站调用全链路独立审计 (Outbound Audit)：新增 sys_mcp_outbound_audit_logs 独立审计表，在服务台全局「审计日志」Tab 中集中展示智能体发起的外部 MCP 工具调用快照、完整入参出参、时延（毫秒）与全局 Trace ID。

3. 🌡️ 模型级 Temperature 采样温度独立配置

  • 精细化温度调优 (0.0 ~ 2.0)：在底层 ai_models 表新增 temperature 字段，允许管理员在模型管理页面中为不同模型单独配置专属采样温度。
  • 智能体创建自动继承与测试覆盖：新建智能体及进行模型连通性测试时，优先自动采用对应模型的专属温度设置；未单独设置时平滑回退至全局默认值，兼顾代码分析严谨性（低温 0.1~0.2）与创意构思灵活性（高温 0.7~0.9）。
  • 前端引导与安全索引访问：前端模型配置面板补充温度参考说明与推荐值提示，修复类型索引安全访问机制。

4. 🛡️ 平台综合体验、元数据调度与安全防线全面加固

  • EmbedChat 浮标与轻量化：嵌入组件反幻觉开关默认关闭提供极速响应，输入框内集成悬浮状态指示与浮标交互，移动端与窄屏体验更优；正文防刷屏熔断周期调整为 15 周期。
  • 元数据大表分批生成与数据库探测优先：实体关系发现支持分批生成与诊断日志，修复截断，取消数量上限；优先根据外键和同名字段进行物理探测，再批量调用 AI，大幅节约 Token；提供元数据同步实时日志流与进度条。
  • Cron 表达式容错自愈与可视化生成：彻底解决历史非法 Cron 表达式导致的任务列表 500 崩溃，统一前后端可视化生成器与双向校验规则。
  • 单次超时基线统一：统一全局单次工具调用超时基准为 60s（agent_max_toolcall_timeout），防止无效任务无限等待。
  • 文件上传防覆盖与下载时效签名：统一文件名安全生成规则，彻底修复同名并发上传覆盖冲突；加固生成文件下载链接的时效性签名校验。
  • 前端排版打磨与在线用户统计修复：统一菜单图标库，优化消息气泡底部操作按钮排版，修复移动端 Excel 导出重复显示及在线用户多标签页计数重复问题。
  • 自动化测试全矩阵覆盖：新增 30+ 组自动化测试用例，涵盖责任链管道、锁看门狗、流式直出、MCP OAuth 等核心模块，同步更新 tests/CHECKLIST.md。

🛠️ 极速升级指引 (Upgrade Guide)

方式一：源码拉取升级（开发与虚机部署） 

# 1. 拉取最新代码
git fetch origin && git checkout main && git pull origin main

# 2. 执行数据库增量升级 (自动幂等执行新版本迁移)
./db-prod/apply-sql-native.sh   # PG 执行: ./db-prod-pg/apply-sql.sh

# 3. 启动/重启平台（自动准备依赖环境）
./dev.sh

方式二：Docker 容器化升级（生产环境推荐） 

# 1. 执行数据库增量升级
./db-prod/apply-sql-native.sh

# 2. 导入官方 Release 镜像归档（以 x86_64 为例）
docker load -i nanzi-ai-agent_1.0.14.0_linux-amd64_*.tar

# 3. 重启容器服务
cd docker && ./start-nanzi-ai-agent.sh
