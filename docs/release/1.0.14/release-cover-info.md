> 想把企业的 Agent、知识库与数据查询开放给外部客户端？NanZi v1.0.14.0 全面开放「平台 MCP 服务台」，支持 Cursor 与 Claude Desktop 直连，提供 OAuth 鉴权、Scope 版本管控与独立审计日志；同时支持多工具并发调度与大表元数据智能发现。
