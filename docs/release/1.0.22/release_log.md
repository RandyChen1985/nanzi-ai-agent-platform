> **⚠️ 升级后行为会变**
>
> **3. 数据集范围从「只打日志」变成硬拦截**：手选与「会话固定」的数据集范围，此前只记录、不生效；本版起在检索与执行两处真拦截，范围外的表直接返回拒绝，委派给子智能体也继承同一范围。如果某个智能体此前靠「跨数据集补全」才查得到关联表，升级后会看到拒绝提示——请把这些数据集一并授权，这是设计使然，不是故障。
>
> **4. 知识库不再直接收图片**：图片改为「多模态模型读成 Markdown → 用户确认 → 入库」，上传白名单已移除图片扩展名。升级前请确认「系统设置 → 模型服务」里有可用的多模态模型，否则图片入口会提示未配置视觉模型。原图不再放在可直接访问的静态目录（改存 `data/knowledge_images`），只能通过带鉴权的接口读取——如果外部系统直接引用过旧图片地址，会失效。
>
> **5. 委派只剩一个开关**：页面上的「子智能体批量调用」并入「子智能体调用」，勾一次两者都开。历史上只配了批量开关的名单，保存时会自动合并并清理，不需要手工迁数据。委派上限也从代码常量改成系统设置里可调（批量任务数 1~20 默认 4，单个专家每轮 1~10 默认 2），改完即时生效，不用重启。
>
> **6. 主助手不能再当团主，也不能被委派**：存量白名单里的主助手会在保存时自动剔除，界面也提供「立即移除」。这条是故意的——主助手是兜底入口，被当成专家会出现「专家把问题丢回给兜底」的循环，而且它被委派进来时深度已经是 1，再往下必然超限。
>
> **🔧 视环境处理**
>
> **7. 沙箱资源上限只对新建容器生效**：Docker 沙箱现在会下发内存上限（默认 2 GiB）、内存交换、CPU 核数（默认 2 核）与进程数（默认 512）四项限制，已运行的容器不会自动套用。需要立即生效就等空闲时段回收重建一次；不重建也不报错，只是仍按旧限制跑。配置语义是「留空沿用默认、填 `0` 表示该项不限、非法值回退默认」——**清空输入框不等于关掉保护**。
>
> **8. 定时任务的「星期」恢复标准写法**：此前填 `1-5` 实际落成「周二到周六」（周一漏跑、周六多跑），本版改按标准 crontab 解释。存的数据本来就是标准值，不需要迁移；但**如果当初为了「跑对」而手工把表达式往后挪了一天，现在要挪回来**——升级前请把 `weekly` 任务逐个确认一遍实际执行日。

## 🚀 Key Features

### 1. 🔐 数据集权限：谁能看哪些表的哪些列、哪些行、到什么时候 (Data Permission Governance)
*   **权限从「一个数据集一把钥匙」变成四层**：数据集、表、字段、行都能单独收窄、能设有效期；表级只做白名单，没配的表默认看不见——新加的表不会自动对所有人开放，宁可拒绝也不漏放。
*   **字段级按「所有人取交集」算**：组织层面禁掉的列，别人单独授权也放不开；查询里引用被禁列直接拒绝，只出现在结果列里就剔掉并明确提示。
*   **行级不再靠猜**：过滤条件改按 SQL 结构判断，不再用正则猜列名——「状态 = ADMIN」这类写法不会再把条件悄悄丢掉；四类空配置统一收敛为「查不到数据」，不会变成不限。
*   **总览一页看清风险**：哪些数据集没人能访问、哪些快到期、哪些被收窄，按风险排序，点进去就能改；数据集支持勾选批量删除。
*   **ChatBI 的范围从「只打日志」变成真拦截**：会话固定的数据集在检索与执行两处都会拦住，委派给子智能体也继承同一范围；指标口径里藏着的完整 SQL 不再透给无权的人。

### 2. 👥 专家团：把「一个万能助手」变成「一位团主 + 一支队伍」 (Expert Team & Delegation)
*   **团主 + 成员，不另建一套名单**：成员直接复用它的委派范围，团里有几个人和实际能调几个永远一致。
*   **专家中心分三类**：系统专家 / 自定义专家 / 专家团，支持按团主、子专家、所属团筛选，改名后筛选不会悄悄失效。
*   **「团队介绍」会整段进提示词**：写「不查不写」它就真的不干活——指引给出 6 种踩坑写法（各自说明会发生什么）与 5 个可直接套用的场景模板。
*   **委派能力分两栏回答**：能调用的、有权限但暂时调不了的，后者逐条说明原因（没装工具 / 未就绪 / 不在白名单）。
*   **上限可调、边界明确**：一次最多几个任务、单个专家每轮几次都在系统设置里改，改完即时生效；主助手不能当团主，也不能被委派。

### 3. 🖥 用户模式：同一个平台，两副面孔 (Dual UI Mode)
*   **一屏上手**：用户模式菜单固定为会话、专家技能、定时任务、知识库、工作空间，专业模式完全不变，登录按角色落到对应界面。
*   **切换只要一步**：两种模式共用同一个头像弹层；用户模式默认亮色、隐藏右侧顶栏，通知与退出收进左下角。
*   **被禁的模式是灰的，不是消失**：可按角色禁用某个界面模式，禁用项显示为灰色加锁，并说明是哪个角色关掉的。
*   **侧栏与会话列表重做**：侧栏可收成图标条；会话按「置顶 / 今天 / 昨天 / 更早」分组，滚到底自动加载、搜索防抖、支持手动刷新。
*   **新增工作空间页**：浏览、上传、下载、预览、解压、回收站、批量操作都有，与聊天里的文件抽屉同源。

### 4. 📚 知识库：千库万文档也能顺手 (Knowledge Workspace)
*   **双栏工作台 + 真分页**：左边目录树、右边文档区，库与文档都按页取（默认 20、可选 50/100），上千个库、几万篇文档不再一次性拉完。
*   **收窄前先看清波及面**：列表新增「引用 / 授权」两列——哪些智能体绑了它、哪些人拿到了权限；每个库还能单独配「能打开的人里谁还能改」，编辑权不等于管理权。
*   **图片先转文字再入库**：由多模态模型读成 Markdown、确认后才入库；原图改走鉴权读取，不再当静态资源裸奔。
*   **智能体也能建库传文档**：只能建个人私有库；上传默认只给预览，用户点头才真传——传错库撤不回来。
*   **检索质量回到控制台水平**：纠正了对上游召回参数的误解，候选池不再被压成个位数。

### 5. 🛡 安全审计：24 项确认问题全部改为「拿不到就拒绝」 (Security Audit Remediation)
*   **越权面**：管理员密钥携带普通用户会话时能拿到管理员权限、模型可读写他人记忆、多表查询里的过滤条件被静默丢弃、知识库门禁把「当时可访问」当成「现在可访问」。
*   **代码执行面**：五个数据库适配器的模板可被注入执行任意代码、脚本试运行在宿主机跑、SQLite 便签可越权附加数据库。
*   **沙箱面**：Docker 沙箱补上内存 / CPU / 进程上限（此前一次死循环就可能把整台机器拖进 OOM），K8s 沙箱关闭集群凭证自动挂载。
*   **静默失效面**：调试接口没有鉴权、降级检索必然空结果、数据集超过 500 个就误判「失联」并阻断问答、SQL 封顶被内层 LIMIT 骗过——这些不报错也不工作的毛病一并修掉。
*   **身份隔离**：换号后侧栏不再沿用上一个身份的菜单，登出清理补齐令牌与本地缓存。

### 6. ⚡ 性能：该省的一次也不做 (Performance & Observability)
*   **改角色权限不再卡死**：1000 人的角色保存从 39.4 秒降到 0.28 秒，耗时基本不再随人数增长。
*   **向量同步只算变过的**：内容没变就跳过重算，连续编辑合并成一次。
*   **列表告别逐条查询**：数据集关系数、权限总览的主体名称都改成批量取。
*   **等待的过程看得见**：从「已提交」到「开始回答」之间开始分段计时，发消息到首字之间的空白也补了进度卡。
*   **测试更快更干净**：全量跑一遍少建 6200 次数据库连接，套件耗时 250 秒降到 194 秒。

## 🐛 Bug Fixes

### 调度、定时任务与 Cron
*   **「工作日」的任务周六也跑了**：存的排期是标准的周一到周五，但底层调度器给星期编号的方式比标准少一天，于是实际落成周二到周六——周一漏跑、周六多跑，而界面按标准显示，看不出错。现在在进入调度器之前统一换算，存储与界面都保持标准写法。
*   **带秒的表达式能保存，却永远不执行**：保存时只校验了前几段，「每天」与「工作日」同时限定也照样入库，但调度器解析时直接失败，表现为「配置成功、从不运行」。现在保存前就拦住，并指出是哪一段写错了。
*   **AI 说「任务创建成功」，任务却从不运行**：工具建任务时完全不校验排期，非法值先入库、随后被悄悄跳过，任务中心还显示「运行中」。现在先校验再入库，并回填下次运行时间，成功与否一眼可辨。
*   **一条配错的订阅，让后面所有订阅都不再排期**：逐条装载没有相互隔离，出错还会连累整个服务起不来。现在单条失败只跳过这一条，其余照常。
*   **四处手输排期的地方提示不一致**：有的是一行淡蓝色小字，有的是弹窗，有的只有范围提示；统一成「输入框标红 + 说清哪一段错 + 保存前拦住」。

### 会话、时间线与交互
*   **流式输出时突然不跟底**：内容一长高，浏览器会自己微调滚动位置，被误判成「用户往上滚了」，从此只提示不跟随。现在只认真实的滚动动作，并放宽自动滚底的保护窗口。
*   **「思考过程」的开关等于没用**：几处监听互相覆盖，判断顺序也写反了，导致「生成完自动折叠」永远不生效——这段逻辑已经改错过两次。现在收敛成一条明确的判断规则，并加了断言防止再排错顺序。
*   **工具卡片跑完一直摊着**：没有任何逻辑在工具结束后收起，一轮几个工具就把整屏铺满执行明细。现在结束即折叠，但用户正在看的那张不会被抢走。
*   **打开长会话没有定位到最后一条**：消息行按固定高度估算，第一次滚到底只到「估算的底部」，历史越长偏差越大。现在强制贴底并补帧。
*   **准备阶段先展开再收起，闪一下**：同一个节点在流式过程中先摊开几行，状态收敛后又收回去。现在默认收起，只有出错或用户点开才展开。
*   **点浮层外面收不起来**：侧栏按钮拦下了点击事件，传不到页面；用户模式还多一层内嵌页面的隔断。现在改为按下即判定，并用一层透明遮罩兜住嵌套区域。
*   **概览页三处数字失真**：图例被裁成「mcp_r…」；条形长度按最大值归一化，最长一项显示 100% 而旁边写 40%；耗时趋势里十几小时无数据被压成两根竖刺；「12 次失败」无处可查。现在图例可读、百分比与条形同源、空白时段单独标注，失败项能直接点进明细。

### 平台、权限与登录
*   **「一键初始化 default 角色」必定失败**：创建接口把所有系统角色码都当成保留字，default 也被拦住；实际只有管理员这一个码带特权，其余三个可以创建、只是不许删。现在只拦真正会提权的那个。
*   **密码快到期提示闪一下就不见**：后端用「最后更新时间」算密码年龄，而它每次登录都会被刷新，已过天数永远归零，快到期状态算不出来。现在改按「密码最后修改时间」算。
*   **MCP 连接测试必然报参数错误**：探测沿用了保存时的必填校验（要求展示名），而新建向导第一步根本没有名字输入框——「填地址 → 点验证」这条主路径 100% 失败，且失败得极快、请求都没发出去。现在探测不再要求名字，保存时仍然必填。
*   **分享里「永久」按钮不高亮**：其实已经生效，只是选中态没覆盖这个选项，点完五个按钮全是灰的，让人以为点不动。现在选中态与提交值同源，不会再出现「写永久、建出 7 天」。
*   **Docker 部署的配置静默失效**：环境变量文件只参与了模板替换、没注入容器，容器里又没有这个文件，跨域白名单等配置会悄悄退回默认值。现在统一注入，同名项仍以显式配置优先。

### 工具、沙箱与嵌入
*   **沙箱容器被删掉后永不自愈**：存活标志只是个普通变量，容器被清理、内存耗尽或别的实例替换后它仍然显示「活着」，而缓存命中时根本不去问 Docker，报错会一直抛给用户。现在定期确认容器还在，不在就就地重建。
*   **图片一律被当成 png**：上游生成的是 jpeg / webp，转换环节写死了 png，严格一点的模型直接判「图片无效」；验证码识别走同一条链，表现为「偶发识别不了」，很难定位。现在按真实类型传。
*   **技能说明被悄悄截断**：读进来二十多万字符、进上下文前砍到六万多，截断处没有任何提示，日志还写着「已完整加载」，被砍掉的尾段恰好是禁止事项与输出格式。现在保留首尾两段并明确标注省略了多少。
*   **知识库链路核实的 10 处问题**：「同步」按钮点了毫无变化；部门成员看得到批量按钮却选不中任何文档；删库漏清收藏与待审批申请；数据集过千后排在后面的库会被漏删成孤儿；删文档后目录记录只增不减。
*   **上游返回非 JSON 时直接崩**：网关返回 HTML 错误页会让解析抛异常。现在提取诊断信息，给出可读的提示。
