⚠️ 升级核心须知 (Upgrade Notes)

  • 数据库迁移必跑：本版新增 12 组迁移（MySQL V188 ~ V201 / PostgreSQL V88 ~ V101；V195/V196、PG V95/V96 为预留编号未使用）。
  • 先迁移再重启：V201 / V101 为执行历史新增 agent_name / agent_display_name；模型已按新结构读写，跳过迁移会 Unknown column 导致历史接口 500。
  • 沙箱镜像必须重建一次：内置 Node 22 / npm / npx、构建走国内镜像源、沙箱内 agentscope 钉后端版本，Dockerfile 参与 tag 哈希，既有镜像全部失效；K8s 策略需重新构建并重建 Pod。
  • 运行时依赖升级：agentscope 2.0.9 → 2.0.11、mcp 1.29.1 → 2.3.0，新增 WebRTC 传导依赖，后端镜像会变大，需重新安装依赖。
  • 平台技能安装权限收紧：平台级安装 / 导入统一由 element:skills:admin 把关（不再依赖角色字符串，未登录同样无法写入）；普通用户入口会消失，如需保留请在角色管理中显式授予。
  • 知识库 TEAM 级语义：归属部门（含下级）成员在 TEAM 可见范围下自动获得只读权限，调整归属部门等于调整可见人群，变更前请确认影响面。

🚀 核心特性 (Key Features)

01 · 知识库企业级治理：归属、可见范围、审计与申请闭环

回答「谁创建、谁维护、谁能看、谁能改」，把知识资产从个人收藏升级为平台治理：

  • 三级可见范围 + 部门归属：统一为个人私有 / TEAM 部门级 / 授权可见，新增业务归属部门，左侧树按部门分组并支持「包含下级部门」；TEAM 级下部门成员自动获得只读，可写仍由归属人与管理员决定。
  • 归属人交接：归属人改为主键判定（管理权唯一真源），支持一键转移交接，候选带部门并标注编辑权限；离职 / 改名的历史库回落旧口径，升级不会误收紧权限。
  • 操作审计与全局审计：创建 / 上传 / 删除 / 授权 / 转交 / 切片变更一库一条留痕，详情页「操作日志」Tab + 管理员跨库查询与 CSV 导出。
  • 访问申请闭环：发现 → 申请 → 审批（待审批 / 已处理、真实总数分页）→ 落授权；提交通知归属人、审批通知申请人；同一人同一资源只能有一条 pending（数据库唯一约束兜底并发）。
  • 检索范围门禁：未显式选库且有效库数超阈值时先确认范围（全部 / 仅默认 / 最相关 N 个 / 我自己指定）；全局总闸 + 智能体四态双层控制，「仅用绑定库」模式一律不弹卡；委派自动收窄、定时任务保持全量。
  • 内容运维与平台治理：文档重命名 / 启停、同名替换、切片增删改与回跳原文、引用影响面、批量操作、配额、零结果率与 P95 检索指标、按天健康巡检、失联库可解释、列表全量翻页与缓存降级。

03 · 会话在线分享与个人身份

一次分析结果不必再导出 Markdown 手动传：

  • 分享即快照：创建时冻结提问与助手最终回复，原会话继续对话 / 被删除 / Redis 过期都不影响；不含思考过程、工具调用与文件路径。
  • 公开或密钥访问：地址与密码分离（密码不进 URL / Referer / 日志），有效期支持 1 小时 / 24 小时 / 7 天 / 30 天 / 永久与自定义。
  • 我分享的：查看打开次数与最近打开时间，复制链接 / 密码、随时作废；只有真正读到正文才计数，并发原子自增。
  • 安全细节：密码 Fernet 密文可回看以便重发，解锁换短期令牌走请求头且不超过分享剩余有效期、绑定单个分享；失效原因不区分，统一 404 防探测。
  • 用户自定义头像：上传 + 256×256 裁剪，删除回退姓名首字；按用户目录隔离、拒绝 SVG、2MB 上限，上传即生效并广播刷新。

05 · 工具生态：脚本工具、JSON 分享与 MCP 进度流

自定义工具从「只能调 HTTP」扩展为「能写脚本、能分享、能看进度」：

  • Python 脚本工具：脚本在会话沙箱内执行（docker / k8s 进容器，local 降级到用户工作区），沙箱不可用时报错而不是在宿主机偷跑；stdin 收 JSON、stdout 出结果、非 0 退出即失败，沙箱内单次超时 clamp 600 秒。
  • 5 个开箱内置脚本：文件转 Base64 / Base64 转文件 / 文件摘要 / 文本脱敏 / 正则抽取；源码只存在代码库，页面可「覆盖」也可「恢复内置默认」。
  • 工具 JSON 导出 / 导入：nanzi.tool.bundle v1，凭据以占位符导出，跨平台分享不再靠截图手工重建。
  • MCP 工具进度流：远端 progress 直通工具卡进度条，补上 Streamable HTTP 传输，端点不可达先 TCP 预检再降级；无进度时也有兜底「在动」反馈。
  • 调试与示例：测试台新增「curl 请求」分页（两步命令、令牌脱敏），Echo MCP 示例升级为可运行 Python / Java 版本，补传输安全与固定 Token 校验。
  • 会话级工具授权：确认卡支持「本会话总是允许」，一次确认覆盖本会话同类调用，跨会话不继承。

06 · AgentScope 2.0.11 升级、执行韧性与流式性能

  • MCP 2.x 适配：端点工厂化 + Transport Security 显式配置，修复「在线调试必失败」的 session manager 生命周期隐患与「对外地址保存不生效」的静默失效。

  • 卡顿与渲染治理：贴底滚动按帧合并、时间线去 O(n²)、递归防环；模型调用条目与底部汇总行按实测性能结论移除，时间线回归纯执行叙事。
  • 分块渲染 + 看门狗：Markdown 按安全空行切块并缓存已完成块，每帧只重算尾块；流空闲 15 秒或 run-status 已结束时自动收敛，不必刷新页面。

🐛 重点缺陷修复 (Bug Fixes)

📚 知识库与资源

· 建库重名绑到别人的库：建库前按名称查未删除元数据拦截 409，RAGFlow 未返回 ID 时只在同名候选唯一时认领。

· 目录操作改可见范围 / 覆盖丢失：目录结构改独立端点，只写目录配置，不再整份 PUT 元数据。

· 内置库出现在「发现」里：内置库判定收敛为单一函数并统一大小写，不再「可申请、批了也用不上」。

· 越界 Dataset ID 静默回落：仅用绑定库时显式指定范围外的库改为明确阻断，部分越界只收窄不整体拒绝。

· 知识库申请查重 500：子类覆写签名与基类调用不一致导致 TypeError，移除覆写并按资源类型分派。

· 审批通过后权限仍不可用：权限缓存清理失败重试一次，仍失败升 error 并写明后果，不再等满一小时 TTL。

🌊 会话、时间线与流式

· 流式终帧正文渲染两遍：直出 / 合成路径不再重复下发正文。

· 消息里 .json 路径被截断成 .js：修复路径解析与「打开」链接插入错位。

· 代码块含反引号被截断：围栏内反引号等长屏蔽后解析再还原，代码卡片完整、后续段落不错位。

· 用户停止后误弹恢复卡片：主动停止不再提示「内容已补齐」，取消提问终态持久化，刷新不再变回「等待回答」。

· 挂起步骤文案噪音：沙箱保留三档递进文案，其余类别只转圈、30 秒后才补「仍在处理中…」。

· 普通用户历史署名空白：写入固化智能体身份快照，读取按行内快照 → Redis → 直查三级回落。

🛠️ 工具、MCP 与沙箱

· MCP 不可达时接口 500：握手前 TCP 预检 + anyio 取消语义兜底，不可达直接降级 Direct HTTP，清洁阶段异常不再打断降级。

· SSE 出站客户端类型错误：mcp 2.x 下返回 httpx2.AsyncClient，否则必然 TypeError 并静默降级。

· 脚本工具在宿主机执行：runner 摘除脚本工具 spec，绑定层显式拒绝，杜绝「以为在沙箱里跑」。

· 失效引用误删有效配置：失效工具解析补上脚本工具，避免一键移除把有效配置删掉。

· RAGFlow 非 JSON 报错崩溃：上游返回 HTML 502 / 网关超时时提取诊断信息，返回友好提示。

· 压缩包无法解压到指定目录：工作区压缩包右键支持「解压到…」。

🛡️ 平台、部署与权限

· 授予功能点后菜单不显示：授予功能点时自动补齐祖先菜单，消除「仅分组」死权限。

· SQL 身份缺失可绕过：身份缺失一律 fail-closed，堵住匿名缓存与无过滤重写。

· 鉴权与聊天 session 活到 SSE 结束：显式声明依赖作用域并提前释放，连接池超时可配并补 pre-ping / recycle。

· Docker 部署回落默认门户地址：compose 补 SSO 环境变量。

· 部门路径编码旁路写入：封死组织架构快照旁路入口，强制走主更新链路校验。

📖 平滑升级指南 (Upgrade Guide)

遵循以下标准步骤即可平滑无缝升级至 v1.0.21.0。请务必注意：本版本新增 12 组数据库迁移必须执行，且沙箱镜像需要重建一次。

方式一：源码拉取升级（开发与虚机部署）

# 1. 同步拉取主分支最新代码

# 2. 执行数据库结构平滑迁移 (MySQL / PG)

bash db-prod/apply-sql.sh # PG: bash db-prod-pg/apply-sql.sh

# 3. 更新依赖环境并启动本地服务

poetry install --no-root && ./dev.sh
