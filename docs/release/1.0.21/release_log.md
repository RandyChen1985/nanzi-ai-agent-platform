# 🎉 NanZi AI Agent Platform v1.0.21.0 Release Notes

**GitHub Repository**: [RandyChen1985/nanzi-ai-agent-platform](https://github.com/RandyChen1985/nanzi-ai-agent-platform)

v1.0.21.0 版本是一次以 **知识库企业级治理（部门归属 / 三级可见 / 归属人交接 / 操作审计 / 访问申请闭环 / 检索范围门禁）、资源广场统一申请、会话历史在线分享、技能广场与沙箱工具链、Python 脚本工具、MCP 工具进度流、AgentScope 2.0.11 运行时升级** 为核心驱动，并全面落地 **流式渲染性能治理、时间线与执行链路精简、移动端与嵌入端交互修复、批量运维能力** 的里程碑版本。

本次变更范围自 `1381e149f58c729d78ec364a2cf083a3de055daa`（含）至 `c5d54aa8`（含），共 **172 个提交**（其中非 Merge 提交 149 个），涉及 **718 个文件**、**133,623 行新增代码** 与 **3,552 行删除**。

> ⚠️ **升级注意**：
> 1. **数据库平滑迁移**：本版本新增 12 组数据库迁移（MySQL `V188 ~ V201` / PostgreSQL `V88 ~ V101`；其中 `V195/V196` 与 PG `V95/V96` 为预留编号，本版未使用），涵盖知识库归属部门与归属人、知识库审计与治理三表、资源广场统一申请表、检索范围门禁配置、pending 申请唯一约束、会话分享、用户头像、优雅收尾开关、脚本工具、历史智能体身份快照。升级时必须按序执行迁移脚本。
> 2. **必须先跑迁移再重启后端**：`V201 / V101` 为 `ai_agent_execution_history` 新增 `agent_name` / `agent_display_name` 两列。模型已按新结构读写，跳过迁移会直接 `Unknown column` 导致历史接口整体 500——这是硬依赖，不是兼容性问题。
> 3. **沙箱镜像必须重建一次**：本版沙箱内置 Node 22 / npm / npx、构建默认走国内镜像源、并把沙箱内 `agentscope` 钉到后端实际版本；Dockerfile 内容参与镜像 tag 哈希，因此既有镜像 tag 全部失效。请在「系统设置 → 安全沙箱」点一次预构建（或首次会话现场构建），K8s 策略需重新构建并导入 `nanzi-sandbox-k8s:<新 tag>`，已运行 Pod 需重建。
> 4. **运行时依赖升级**：`agentscope 2.0.9 → 2.0.11`、`mcp 1.29.1 → 2.3.0`（上游强制 `mcp>=2.0.0`），新增 `aiortc` / `av` 等 WebRTC 传导依赖，后端镜像会相应变大；升级后需重新安装依赖。
> 5. **平台技能安装权限收紧**：平台级技能的安装 / 导入统一由 `element:skills:admin` 把关，不再依赖角色字符串，未登录请求同样无法写入平台技能库；技能广场对未授权用户不再下发平台安装提示词。升级后普通用户将看不到「安装到平台技能库」入口，如需开放请在角色管理中显式授予该功能点。
> 6. **知识库 TEAM 级语义**：`owner_dept_id` 不是纯展示字段——在 TEAM（部门级）可见范围下，归属部门（含下级部门）成员据此自动获得**只读**权限。调整归属部门等于调整可见人群，请管理员在变更前确认影响面。

## 🚀 Key Features

### 1. 📚 知识库企业级治理：归属、可见范围、审计与申请闭环 (Knowledge Governance)
*   **三级可见范围与部门归属**：
    *   知识库统一为 **个人私有 / TEAM 部门级 / 授权可见** 三档（原「公共级」更名为「授权可见」），UI 文案与判定口径全站对齐；
    *   新增 `owner_dept_id` 业务归属部门，左侧知识库树支持按部门分组与「包含下级部门」过滤；TEAM 级下归属部门成员自动获得只读权限，可写判定仍由归属人与管理员决定；
    *   部门级知识库的部门成员可维护文档内容，权限边界与「谁能改」显式区分。
*   **归属人交接与离职兜底**：
    *   归属人由用户名快照改为用户主键 `owner_user_id`，成为管理权（可读可写可删可授权）的唯一真源；`created_by` 降级为创建人历史快照；
    *   支持「转移归属」一键交接，候选用户带部门归属并标注是否具备编辑权限；存量按 `user_name` 回填，对不上（改名/离职/脏数据）的保持 NULL 并回落旧口径，升级不会误收紧任何人的权限；
    *   归属人授权不可被普通「取消授权」撤销，变更必须走转移流程，避免无主库。
*   **操作审计与全局审计**：
    *   新增知识库业务审计表，创建 / 上传 / 删除 / 授权 / 转交 / 切片变更等动作一库一条留痕，库被删除后日志保留；
    *   详情页新增「操作日志」Tab，管理员可在知识库页按人 / 动作 / 时间 / 关键词跨库查询，并导出 CSV（带 UTF-8 BOM，Excel 直接打开不乱码）。
*   **访问申请与审批闭环**：
    *   未授权用户可在「发现」中看到 TEAM / 授权可见的知识库并发起申请（个人私有不露出），管理员短路口径下不产生可申请对象；
    *   审批端提供「待审批 / 已处理」双 Tab、真实总数与分页；审批人只看自己名下的库（管理员看全平台）；
    *   提交时站内通知库归属人、审批后通知申请人（驳回带意见），通知失败不影响审批与授权；
    *   审批通过即写入 `ResourcePermission`（与手工授权等价），撤回与审计沿用既有链路；同一人对同一资源只能有一条 pending，数据库层用生成列 + 唯一键（PG 用部分唯一索引）兜底并发重复申请。
*   **检索范围门禁（Scope Gate）**：
    *   当「知识库轮次 + 本轮未显式选库 + 会话未确认范围 + 有效库数超阈值」四个条件同时成立时，先让用户确认检索范围：全部 / 仅智能体默认 / 最相关 N 个 / 我自己指定；
    *   全局 `system_configs` 三键（总开关 / 阈值 / 最相关库数）+ 智能体 `engine_config.scope_gate` 四态（跟随全局 / 强制开启 / 关闭 / 仅用绑定库）双层控制，全局总闸优先级最高，可一键止血；
    *   「仅用绑定库」模式忽略本轮传入 ID 与其他可访问库，一律不弹确认卡，工具层显式传 ID 也会与绑定求交；聊天与调试页常驻提示条说明当前生效范围；
    *   无人值守场景自动降级：委派按「最相关 N 个」自动收窄，定时任务保持全量（避免静默降权召回），`ask_user_question` 直接返回错误而非空等。
*   **内容运维与平台治理**：
    *   文档重命名 / 启停（停用后切片保留但不召回）、同名上传三选一（替换 / 保留两者 / 跳过）、切片增删改与启停、切片一键回跳原文页码；
    *   引用影响面：详情页展示「被 N 个智能体引用」并可点开名单，删除前强制列出受影响智能体；
    *   批量操作：库勾选批量删除、文档勾选批量解析 / 删除；
    *   配额与容量：每人 50 库 / 每库 2,000 文档，可配置、`0` 表示不限，超限文案给出「现在多少 / 上限多少 / 怎么办」，统计失败不拦上传；
    *   检索效果：记录每次检索的命中数与耗时，给出查询量、**零结果率**、平均命中、P95 延迟与「Top 搜不到的 query」；
    *   健康巡检：按天落快照（文档数 / 已解析 / 解析中 / 失败 / 切片数 / 是否失联 / 停留天数），汇总失联、空库、解析失败与 90 天未更新；失联库不再静默消失，归属人能看到「失联了」而不是凭空不见；
    *   列表性能：列表按 `total` 翻完全部页（修掉 >1000 条静默截断）、页间并发去重、60 秒 TTL + 单飞锁、引擎不可用时返回上次快照并标 `stale`；
    *   上传口径统一为 256MB + 扩展名白名单，后端分块读取边读边卡上限，不再整份读进内存；
    *   知识库管理默认落地「概览」页（知识库数 / 文档数 / 被引用数 / 待关注项、最近更新、可见范围分布），不再自动打开第一个库。

### 2. 🧭 资源广场：知识库与数据集的发现、申请、审批 (Resource Square)
*   **工作台新增「资源广场」Tab**：聚合授权可见 / TEAM 级知识库与全部启用数据集，支持关键词搜索、状态与可见范围筛选、分页加载；卡片标题支持一键复制资源名。
*   **统一访问申请**：知识库与数据集走同一条「申请 → 审批 → 落授权」链路，审批统一在用户管理页，按资源类型混排分页；「我的申请」并入「我的权限」子 Tab，带类型标识。
*   **只读概览页**：为「被授权但没有管理菜单」的账号提供知识库 / 数据集只读概览，路由守卫按只读页放行，不再被送到无权限页。
*   **申请质量治理**：停用数据集不可申请、资源改私有后审批前拦截、`resource_id` 归一化、理由 / 意见超长 400、审批行锁防并发双批、缓存清理失败重试并升级告警；申请成功给顶部提示，错误文案透传后端原因而不是 `Request failed with status code 403`。
*   **工作台入口一致**：资源入口卡片与广场使用同一候选集（过滤已删除、内置库、未同步授权），数字不再出现「工作台 32 / 广场 29」的口径差。

### 3. 🔗 会话在线分享与个人身份 (Conversation Sharing & Identity)
*   **分享即快照**：创建分享时冻结当时的提问与助手最终回复，之后原会话继续对话、被删除或 Redis TTL 到期都不影响分享页；不含思考过程、工具调用、SQL 与文件路径。
*   **访问方式与有效期**：支持公开或密钥访问（地址与密码分离，密码不进 URL / Referer / 日志），有效期预设 1 小时 / 24 小时 / 7 天 / 30 天 / 永久，也支持自定义小时或天。
*   **分享管理**：侧栏「我分享的」视图展示打开次数与最近打开时间，支持复制链接 / 复制密码 / 随时作废；只有真正读到正文才计数，并发用原子自增。
*   **安全细节**：密码以 Fernet 密文保存（可回看以便重发），解锁换短期令牌走请求头且不超过分享剩余有效期，令牌绑定单个分享；访问计数不区分失效原因，统一 404 避免探测 share_id 是否存在。
*   **用户自定义头像**：个人中心支持上传头像、按 256×256 裁剪、删除后回退姓名首字；头像按用户目录隔离（与全局 AI 头像、智能体头像互不清理），刻意拒绝 SVG，2MB 上限，上传即生效并广播 `user-info-updated`，聊天页左下角自动刷新。

### 4. 🧠 技能资产、技能广场与沙箱工具链 (Skill Assets & Sandbox Toolchain)
*   **工作台新增「技能广场」**：首批 21 个精选技能（覆盖四个来源仓库），分类浏览 + 搜索 + 详情抽屉，复制提示词即可交给智能体安装；补齐「装完之后」闭环，已装/可更新状态可见。
*   **技能可以带脚本、模板与图片**：新增 `write_skill_file` 工具，支持文本与 Base64 二进制写入技能目录；路径必须相对且落在技能目录内（拒绝绝对路径、`..`、隐藏文件与 `SKILL.md` 覆盖），默认不覆盖，目录文件数与容量预算与上传解压同源。
*   **沙箱装的技能可收录进平台**：新增 `import_skill_from_sandbox`，把 `npx skills add` 装到会话工作区的技能整目录搬进个人技能库（含脚本/图片等二进制资源），原子替换、跳过符号链接、frontmatter 缺失只告警不拒绝。
*   **沙箱运行时补齐**：Docker 与 K8s 沙箱统一内置 **Node 22 / npm / npx**（写死版本，构建期自检 `node --version`）；构建默认走国内镜像源（apt 清华 + uv index，可用配置回退官方源）；沙箱内 `agentscope` 钉到后端实际版本，修复「重建镜像后 gateway 起不来」。
*   **依赖安装口径统一**：提示词、工具描述与 Bash 返回的 `hints` 一致指向 `uv pip install --target /workspace/.pylibs` + `PYTHONPATH`，并明确「裸 pip 装完默认 python 看不到、容器可写层只有 `/workspace` 保留」；`session_status` 增加沙箱运行时说明。
*   **代码画布按沙箱策略执行**：画布「运行」在 docker / k8s 策略下进沙箱执行（路径按沙箱逻辑根换算），输出区标注执行后端；e2b / ssh 明确拒绝并提示切换策略，不再出现「报错路径是宿主、用户在沙箱里找不到」的误判。
*   **平台技能安装 / 导入统一门禁**至 `element:skills:admin`（进程内 TTL 缓存 + 会话启动预热，缓存未命中按拒权处理），安装提示词兜底超时与平台工具调用超时（180 秒）对齐。

### 5. 🛠 工具生态：脚本工具、JSON 分享与 MCP 进度流 (Tool Ecosystem)
*   **新增 Python 脚本工具**：
    *   与 API 工具并列的第二种自定义工具，脚本在**会话沙箱**内执行（docker / k8s 进容器，local 降级到用户私有工作区），沙箱不可用时报错而不是偷偷在宿主机跑；
    *   运行契约：stdin 收 JSON、stdout 出结果（可解析则结构化）、非 0 退出码即失败、stderr 作为错误详情；沙箱内单次执行超时 clamp 到 600 秒；
    *   内置 5 个开箱脚本：文件转 Base64、Base64 转文件、文件摘要（MD5/SHA）、文本脱敏、正则抽取；内置脚本源码只存在代码库，页面上可「覆盖」也可「恢复内置默认」；
    *   页面如实提示执行位置（沙箱内 / 本地工作区），e2b / ssh 策略明确不支持；支持按来源 / 状态 / 分组筛选、批量设置分组。
*   **工具 JSON 导出 / 导入**：API 工具与脚本工具支持导出为 `nanzi.tool.bundle` v1 文件并导入，凭据以占位符形式导出（不携带真实密钥），跨平台分享不再靠截图手工重建。
*   **MCP 工具进度流**：远端 `progress` 直通工具卡进度条；补上 Streamable HTTP 传输（Direct HTTP 降级下进度永不生效）、会话不再误重置状态、端点不可达时先做 TCP 预检再降级，避免同步失败拖垮接口；远端不报进度时也有兜底「在动」反馈。
*   **MCP 调试体验**：工具测试台新增「curl 请求」分页，按真实调用生成两步命令（`initialize` 拿会话 + `tools/call`），用户断言 JWS 与静态令牌只给占位符说明；业务方 MCP 模拟代码升级为完整可运行的 Echo MCP 示例（Python / Java），补传输安全配置与固定 Token 校验。
*   **会话级工具授权**：工具确认卡新增「本会话总是允许」，一次确认覆盖本会话后续同类调用，跨会话不继承，恢复挂起执行时同样生效。
*   **运行时元数据健壮性**：`runtime_metadata` 非 Mapping 时按空处理并返回副本，不再带崩整轮执行。

### 6. ⚙️ AgentScope 2.0.11 升级、执行韧性与流式性能 (Runtime & Execution Resilience)
*   **运行时升级与验收**：`agentscope 2.0.9 → 2.0.11`、`mcp 1.29.1 → 2.3.0`；完成 P0–P2 全模块验收与 26 模块使用情况盘点，升级未删除任何平台在用能力，3 处行为变化（并行工具取消语义、危险路径 `realpath`、DataBlock `workspace:///`）均已适配。
*   **MCP 2.x 适配**：`FastMCP → MCPServer`、端点工厂化与 Transport Security 显式配置、会话空闲 1 小时、请求体 32 MiB；修复「在线调试必失败」的 session manager 生命周期隐患，以及 `settings.transport_security` 静默失效导致「对外地址保存不生效」。
*   **步数将尽优雅收尾**：新增 `agent_graceful_finish_enabled` 开关，步数将尽时注入收尾提示并禁用工具调用，让模型基于已有信息作答，替代直接输出「达到最大执行步骤」模板文案。
*   **执行时间线可观测性**：挂起工具行显示「已耗时 / 超时上限」（分母取版本级优先的实际生效值，≥90% 转琥珀色），Bash 声明 `description` 参数并在工具描述中要求写意图摘要（`Bash · 检查 5432 端口是否被占用`）；工具 / 旁白 / 子步骤统一走同一套耗时渲染。
*   **委派场景卡顿治理**：贴底滚动按帧合并、时间线组装去 O(n²)、递归防环；实测「模型调用条目 + 底部汇总行」在委派场景反复入队出队，最终**移除模型调用条目与底部汇总行**——时间线只保留旁白、工具步骤、思考过程与 fallback 换模提示，观测信息不再参与流式刷新。
*   **长回答分块渲染**：Markdown 按「安全空行」切块并缓存已完成块，每帧只重算尾块，渲染结果与整体渲染逐字符一致；修复代码块内容含三反引号时被提前闭合、后续段落错位的问题（等长屏蔽围栏内反引号，解析后还原）。
*   **流卡死自愈**：新增前端看门狗——空闲 ≥15 秒或 run-status 判定已结束时自动 abort 并按 run-status / 历史收敛，不必刷新页面；等待权限确认与外部执行时不中止；`finally` 与切换会话都会停表并清理，避免误中止新会话。
*   **取消与恢复语义**：用户主动停止不再误弹「内容已补齐」恢复卡片；取消提问的终态持久化，刷新后不再变回「等待回答」；恢复挂起执行、外部执行二次挂起状态保持 `pending`。
*   **可观测性细节**：子代理 token 明细归入父会话并修正 trace 步骤编号；历史消息的智能体署名在写入时固化快照，读取按「行内快照 → Redis 快照 → 智能体直查」三级回落，普通用户不再看到空白署名。

### 7. 📱 交互与嵌入体验：移动端、工作台与运维入口 (UX, Embed & Ops)
*   **移动端布局修复**：chat 页顶栏默认收起为一条把手（点开/收起，不占用 iframe 热区）；新增右侧「我的账号」把手，进得去也出得来，与账号页把手同断点、互不遮挡；整页定高改跟随 `visualViewport`，底部输入框不再被地址栏 / 软键盘压住（桌面端零影响）；用户 / 角色管理工具栏在窄屏压成一行。
*   **嵌入端体验**：首屏骨架延后到「会话 + 历史 + 快照」全部落地，消除「欢迎页闪一下再跳消息列表」；加号菜单支持「数据 & 知识库」一键挂载；新增「隐藏聊天头像」开关，左右各还 40px 给正文；锁定智能体时历史侧栏明确提示范围，首屏历史不再空白需手刷；宿主快捷提问交接修复（刷新不重发、不被首屏历史清掉）；嵌入端安全加固与首屏加载优化。
*   **工作台与任务中心**：任务中心新增 Cron 可视化生成器（常用周期 + 自定义 + 下次运行时间预览）；工作台静默提示条改中性灰并收敛同义文案。
*   **用户与组织运维**：用户管理支持批量改密与邮件批量重置密码（逐用户随机密码、管理员界面不回显明文、发信失败不改密码、跳过当前管理员）；角色分配用户弹窗支持按部门筛选；部门下拉支持关键词搜索。
*   **SSO 与登录**：`check/login` 透传 `loginType`（兼容 portal-web 必传），区分「协议参数错误」与「认证失败」；新增 `SSO_LOGIN_AD` / `SSO_LOGIN_LOCAL` 登录方式开关，被关闭的方式前后端同时拒绝；登录页 API Key Tab 不再「出现又消失」。
*   **镜像交付自动化**：新增 GitHub Actions「Docker 镜像构建」workflow——手动触发可指定版本号、平台（x86 / arm / both）与是否上传 tar 产物，`v*` tag 自动触发；按触发方式动态生成构建矩阵，选单平台只起 1 个 job，选 both 或打 tag 时双架构并行。
*   **ChatBI 与提示词**：数据集目录静默注入系统提示，超预算时省略表描述明细；绑定数据集后向用户提示生效范围并禁用手动挂载；提示词编辑器补注入说明面板。

## 🐛 Bug Fixes

### 知识库与资源
*   **建库重名绑到别人的库**：建库前按名称查未删除元数据并拦截 409；RAGFlow 未返回 ID 时只在「同名候选唯一」时认领，不再兜底取 `matched[0]`。
*   **目录操作改可见范围 / 覆盖丢失**：目录结构改独立端点，只写 `extra_config.folder_structure`，不再整份 PUT 元数据。
*   **平台内置库出现在「发现」里**：内置库规则收敛为单一判定（`meta-` 前缀 / `chatbi-example` / 空名），并按大小写统一，避免「可申请、批了也用不上」。
*   **越界 Dataset ID 静默回落**：`bound_only` 下工具显式指定范围外的库改为明确阻断并提示；部分越界只收窄不整体拒绝。
*   **知识库申请查重 500**：子类覆写 `pending_for` 与基类三参调用签名不一致导致 `TypeError`，移除覆写并按 `resource_type` 分派。
*   **审批通过后权限仍不可用**：权限缓存清理失败改为重试一次，仍失败升 `error` 并写明后果，不再让用户等满一小时 TTL。
*   **失联库列表样式与口径**：滚动区限高 + 条目化，「共 N 个，列出前 20」与 KPI 对齐；顶部去掉与概览重复的同步入口。

### 会话、时间线与流式
*   **消息里 `.json` 路径被截断成 `.js`**：修复路径解析与「打开」链接插入错位。
*   **流式终帧正文渲染两遍**：直出 / 合成路径不再重复下发正文。
*   **确认卡超时不可见、待确认期间释放输入框**：确认卡超时状态可见，等待期间保持输入锁。
*   **执行时间线工具在上、模型调用在下**：曾把模型调用折叠为一行汇总，最终按实测性能结论彻底移除模型调用条目与底部汇总行，时间线回归纯执行叙事。
*   **挂起步骤文案噪音**：沙箱保留三档递进文案，其余类别只转圈、30 秒后才补「仍在处理中…」。
*   **流式正文含反引号被截断**：围栏内反引号等长屏蔽后解析再还原，代码卡片内容完整、后续段落不错位。
*   **子代理 token 不进父会话**：明细归入父会话并修正 trace 步骤编号。

### 工具、MCP 与沙箱
*   **MCP 不可达时接口 500**：握手前 TCP 预检 + anyio 取消语义兜底，不可达直接降级 Direct HTTP，清理阶段跨 task 的 cancel scope 异常只告警不打断降级。
*   **SSE 出站 `httpx_client_factory` 类型错误**：mcp 2.x 下返回 `httpx2.AsyncClient`，否则必然 `TypeError` 并静默降级。
*   **沙箱工具集失配**：内置 Bash MCP 失配时自动重建，不再长期不可用。
*   **脚本工具在宿主机执行**：runner 一并摘除脚本工具 spec，绑定层显式 `sandbox_degraded` 拒绝，杜绝「以为在沙箱里跑」。
*   **脚本工具信封被截断**：单段输出压到 40KB 并断言两段之和小于通道保留上限，退出码不再丢头。
*   **失效引用误删有效配置**：`resolve_unresolved_tool_names` 补上脚本工具，避免智能体显示「工具已不存在」后一键移除把有效配置删掉。
*   **RAGFlow 非 JSON 报错崩溃**：上游返回 HTML 502 / 网关超时等非 JSON 响应时提取诊断信息返回友好提示。
*   **工作区下载格式白名单误拦**：移除后缀白名单，合法二进制与 zip 均可安全下载。
*   **压缩包无法解压到指定目录**：工作区压缩包右键支持「解压到…」。

### 平台、部署与权限
*   **授予功能点后菜单不显示**：「仅分组」死权限——授予功能点时自动补齐祖先菜单。
*   **SQL 身份缺失可绕过**：身份缺失一律 fail-closed，堵住匿名缓存与无过滤重写。
*   **鉴权与聊天 session 活到 SSE 结束**：显式声明依赖作用域，鉴权 session 提前释放；连接池超时可配并补 `pool_pre_ping` / `pool_recycle`。
*   **Docker 部署回落默认门户地址**：compose 补 SSO 环境变量。
*   **元数据探活误报知识库配置缺失**：改读 `ragflow_*` 配置。
*   **密码设置弹窗点不开 / 确认按钮折行**：「修改密码」文案缩短并禁止折行，设置密码弹窗正常唤起。
*   **部门路径编码旁路写入**：封死组织架构快照的旁路更新入口，强制走主更新链路校验。
