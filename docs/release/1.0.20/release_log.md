# 🎉 NanZi AI Agent Platform v1.0.20.0 Release Notes

**GitHub Repository**: [RandyChen1985/nanzi-ai-agent-platform](https://github.com/RandyChen1985/nanzi-ai-agent-platform)

v1.0.20.0 版本是一次以 **智能体系统级全生命周期管控（申请/审核/发布/下架/转交）与配置分享、多部门多层级组织架构治理、动态菜单入库与三层权限解耦、个人资产协同生态（个人 MCP/技能分享给同事）、会话流式交互单写入方闭环（彻底根治恢复重复与内容回退）、站内信每日定时清理与平台安全加固** 为核心驱动，并全面落地 **API 工具动态变量与请求签名、邮件发送原生附件支持、工作区批量操作、移动端操作栏 Token 用量与纵向滚动条根治、模型配置可视化诊断** 的里程碑版本。

本次变更范围自 `92ce5b544065ba2c13f9ff7590d413a7dc762f49`（含）至 `a4bc751dfc6161e27db44f5726c646b60b8c73ff`（含），共 **166 个提交**（其中非 Merge 提交 144 个），涉及 **806 个文件**、**94,445 行新增代码** 与 **5,328 行删除**。

> ⚠️ **升级注意**：
> 1. **数据库平滑迁移**：本版本新增 15 组数据库迁移（MySQL `V173 ~ V187` / PostgreSQL `V74 ~ V87`，注：`V184` 为 MySQL 专属历史长文本扩展），涵盖 API 工具请求签名、数据源/MCP 独立权限、菜单动态表与角色关系清理、多部门架构表、技能与 MCP 分享表、邮件附件声明、系统对外地址收敛、智能体系统级发布与配置分享、站内信保留期清理索引。升级时必须按序执行迁移脚本。
> 2. **智能体生命周期与隔离**：新版本严格收敛了普通用户与平台系统级智能体的隔离边界。普通用户仅能查看与编辑自建智能体，若需升级为全员可见的系统级智能体，必须通过「上线申请」流程由平台管理员审批。
> 3. **动态菜单与权限配置**：左侧菜单现已全面入库（`sys_menus`）。若对菜单顺序、名称、图标或外链有定制需求，拥有 `element:menu:edit` 权限的管理员可直接在「系统管理 → 菜单管理」中动态维护，无须修改前端源码。
> 4. **站内信 30 天自动清理**：已在系统每日凌晨 02:00 的审计维护任务中挂载站内信自动清理逻辑（保留 30 天）。配合 `V187/V87` 索引，微批异步清除过期消息，防止历史通知无限膨胀。

## 🚀 Key Features

### 1. 🤖 智能体系统级全生命周期流转与配置分享 (Agent System Publication & Sharing)
*   **系统级智能体生命周期闭环**：
    *   **草稿迭代与申请流转**：系统级智能体支持维护独立草稿版本，支持由作者发起「上线申请」并填写更新说明；平台管理员在专属「审核中心」查看版本差异、审批通过或驳回附带原因；
    *   **安全下架与所有权转交**：系统级智能体下架需填写下架原因并记录审计；支持将智能体所有权一键安全转交至其他指定用户；
    *   **版本安全防线**：处于待审状态的版本严格禁止随意篡改与删除（防止申请单孤儿与智能体死锁），审核写路径引入行锁与并发竞态防护。
*   **智能体配置一键分享（配置副本分发）**：
    *   支持用户将自己配置好的智能体一键分享给指定同事（基于 JSON 快照分发副本）；
    *   接收方可在待处理分享列表中选择接受，系统将自动基于快照克隆一份归属于接收方的独立智能体，并贴心引导停留在配置第一步；
    *   支持 7 天惰性过期、分享记录可撤回并通知接收人；创建权限受 `element:agent:create` 严格管控；RAGFlow/OpenClaw 等外部引擎实例由于网络与凭据隔离，严谨禁用分享。
*   **提示词工坊多维隔离与平台基线保护**：
    *   提示词工坊按维护者隔离，普通用户仅可见自建提示词，彻底收口跨用户越权读取与篡改；
    *   平台基线提示词仅管理员可见并维护，`active-config` 接口严格校验归属，防止敏感系统提示词泄露。

### 2. 🏢 多部门多层级组织架构治理与数据权限 (Department Management & Multi-Department RBAC)
*   **全新「部门管理」模块**：
    *   支持无限层级的树形部门架构体系，支持新增、重命名、排序、调整上级部门；
    *   底层采用 `org_path` 编码路径设计，兼顾树形展开性能与深层级检索效率；
    *   子树视图智能收敛，重选主部门自动校准排序；支持在部门成员列表中就地进入用户编辑抽屉。
*   **跨系统部门同步与智能体感知注入**：
    *   第三方用户目录同步（LDAP / 企业微信 / 钉钉等）全面打通部门归属字段映射；
    *   **AI 运行时部门感知**：智能体运行时自动注入可读部门名称，彻底根治大模型回答「我是什么部门」时输出 `/1/` 机械代码的缺陷。
*   **角色成员管理与统计校准**：
    *   角色管理支持直接在右侧抽屉内就地查看并维护所属成员；
    *   修复角色列表用户数虚高与统计统计脏数据，支持按成员数快速排序。

### 3. 🧭 动态菜单入库与系统权限三层解耦 (Dynamic Menu Management & Three-Tier Permissions)
*   **全站菜单入库与动态配置**：
    *   平台左侧导航菜单全面沉淀入库（`sys_menus`），新增「菜单管理」可视化配置页面；
    *   支持自定义菜单名称、路由、图标、排序、父子层级，支持配置外部链接（在新窗口或 iframe 内嵌打开）；
    *   支持标注「仅桌面端可见」菜单，并提供一键筛选视图，方便移动端与桌面端自适应管理。
*   **界面访问与操作权限解耦**：
    *   将界面访问控制（`menu:*`）与具体功能操作控制（`element:*`）彻底解耦，消除菜单与按钮绑死的历史包袱；
    *   我的权限与用户分配视图升级为清晰的三层可折叠树形结构，角色授予权限与直接分配权限标色区分；
    *   数据源管理（`element:datasource:*`）与 MCP 工具集（`element:mcp:*`）权限全面细化独立，精确把控连接与操作边界。

### 4. 🤝 个人资产协同共享生态（MCP 与技能分享） (Personal Assets Collaboration)
*   **个人 MCP 服务与工具集分享**：
    *   支持用户将个人调试或接入的专属 MCP 服务安全分享给同事；
    *   接收方可一键安装至自己的工具空间，内置调用概览与向导校验，降低团队重复接入成本。
*   **个人技能安全分发**：
    *   个人创建的高级公共技能支持直接分享给团队成员；
    *   技能包上传大小上限提升至 **100MB**，解压逻辑改走异步线程池，文件数量上限放宽至 **20,000**，全面支持大体量复杂专业技能包；
    *   用户账号注销或删除时，智能解绑发布作者并保留谱系完整性，杜绝资产孤儿。
*   **个人 MCP 调试与易用性跃升**：
    *   个人 MCP 工具集新增内置 Echo 本地回显测试服务，无须外部网络即可完成通道校验；
    *   未保存的用户身份传递参数支持「先保存再测试」，编辑 MCP 服务不再静默覆盖重命名。

### 5. 🌊 会话流式交互单写入方闭环与恢复韧性 (Chat Single-Writer Replay & Stream Recovery)
*   **确立恢复流程「单写入方」模型（Single Writer Replay Contract）**：
    *   针对切会话/刷新恢复时，偶发的「事件续显轮询与客户端实时流同写一条消息导致整段回复重复输出」历史顽疾，确立单写入方核心铁律；
    *   恢复器闸门严格依据 `streamInFlight`，实时流在途时绝对禁止续显抢写与虚假补草稿；
    *   首拉轮询一律先清空累加字段并全量重建（即使日志被 LTRIM 截断出现断层也不再保留前缀追加），彻底消除重叠段双写。
*   **写入方令牌与代次作废机制**：
    *   引入 `liveWriterToken`：切会话与新流开启时自增，恢复流收尾校验令牌归属，彻底封堵旧流跨会话误清锁态；
    *   引入 `streamReplayGeneration`：在让位、新轮次、切会话与收敛时无条件递增代次，在途网络轮询返回时比对代次，过期结果整批抛弃，不动游标防内容回退。
*   **权限恢复流状态保持与卡片防漏**：
    *   修复恢复流末尾遇到二次外部挂起（`awaiting_external_execution`）时被误判为 `completed` 的缺陷，状态准确保持为 `pending`，防止提交区隐藏导致后端挂起超时。
*   **移动端操作栏与纵向滚动条根治**：
    *   移动端 AI 消息操作栏右侧空位直接露出 Token 用量（「圆柱图标 + 50.6K tok」），紧凑不占行；
    *   精准根治移动端操作栏右侧/底部多出的上下固定灰条（4 个 hover 气泡移动端不渲染，容器纵向显式裁剪）。

### 6. 🔒 平台安全、存储与运维韧性加固 (Platform Security, Storage & Operational Resilience)
*   **站内信 30 天保留期定时清理**：每日凌晨 02:00 定时对账清理超过 30 天的已读/未读站内通知，PostgreSQL 与 MySQL 分别采用针对性方言高优批量执行，新增 `created_at` 单列索引保障毫秒级扫描。
*   **API 工具能力深度拓展**：
    *   支持 `{user.xxx}` 动态用户变量注入，满足千人千面的上下文请求；
    *   新增系统级参数定义与试跑抽屉，并落地请求确定性数字签名。
*   **邮件工具附件支持**：`send_email` 系统工具原生支持本地工作区文件作为邮件附件投递。
*   **全站 XSS 与安全消毒层**：模型流式输出与知识库 Markdown 原文在送入渲染前统一经过严格消毒，放行 `quick:` / `canvas:` 业务协议，彻底拦截非法 `<style>` 标签逃逸。
*   **模型配置可视化诊断**：模型连接失败时提供可视化诊断看板，直观展示测试过程、耗时与上游原始返回，一键快捷复制排障详情。

## 🐛 Bug Fixes

### 智能体与生命周期
*   **待审版本被误删导致孤儿申请单**：待审状态的版本加入保护锁禁止物理删除，防止对应申请单悬空及智能体永久处于不可编辑态。
*   **智能体中心切换到分享视图白屏**：修复分享视图数据结构与搜索框绑定冲突，分享面板保留检索过滤。
*   **非管理员复制他人系统级智能体**：统一归属判定，严格限制普通用户仅能查看自建智能体，禁止通过复制接口私自克隆系统智能体。
*   **模型切换白名单误拦截**：修复版本配置切换模型时校验逻辑遗漏当前生效模型的边界缺陷。
*   **只读智能体配置异常引导错误**：只读智能体出现工具失效等配置异常时，提示文案由修改按钮自动转为联系管理员。

### 组织与权限
*   **权限树脏数据与残留关联**：清理历史遗留的孤儿用户角色关联数据（`V177/V78`），修复成员数统计虚高。
*   **角色搜索搜不到默认角色**：业务角色搜索改走服务端精准过滤，修复前端分页下搜不到 `default` 角色的问题。
*   **设置密码点击无响应**：修复管理端为特定用户设置密码弹窗无法正常唤起的交互 bug。
*   **部门路径编码写入旁路**：封死组织架构快照的旁路更新入口，强制走主更新链路校验。

### 会话与恢复机制
*   **会话恢复流重复回放前序内容**：通过单写入方机制与代次丢弃策略，彻底解决刷新/切页面恢复时正文双显与思考叠加。
*   **切会话历史侧栏卡在加载态**：会话切换收尾动作全面转入后台异步处理，解决侧边栏快速连点时界面冻结在 loading 的卡死现象。
*   **嵌入式会话 401 偶发报错**：修复 EmbedChat 嵌入鉴权 Header 提取与跨域携带凭证，拉齐测试基线。
*   **@ 浮层挂载工作区文件失效**：增强输入框 `@` 文件面板解析逻辑，支持直接将工作空间文件挂载至当前轮对话上下文。

### 工具、MCP 与存储
*   **对话历史长文本落库整行丢失**：MySQL 消息历史表字段由 `MEDIUMTEXT` 扩容至 `LONGTEXT`（`V184`），支持超大体量代码与 Markdown 存储。
*   **MCP 远端已删除工具残留**：对于远端已下线的 MCP 工具，提供一键清理能力，并改用平台标准 tooltip 明确说明原因与恢复路径。
*   **RAGFlow 异常响应解析失败**：当上游 RAGFlow 返回非 JSON 格式报错（如 HTML 502/网关超时）时，提取诊断信息返回友好错误提示，杜绝 JSON 崩溃。
*   **工作区下载格式白名单误拦**：移除工作区文件下载的格式后缀白名单限制，任意合法二进制文件与 zip 均可原样安全下载。
