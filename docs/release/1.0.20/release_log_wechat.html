🚀 核心特性 (Key Features)

01 · 智能体系统级全生命周期管控与配置分享

彻底解决企业场景下智能体线上迭代混乱、缺乏审批流程的痛点：

  • 发布与审核流转闭环：系统级智能体支持草稿独立维护，变更需由作者提交「上线申请」；平台管理员在审核中心比对版本差异、通过或驳回并留痕；支持安全下架与所有权一键转交。
  • 防并发与待审版本保护：处于审核中的版本加保护锁严禁随意改删，杜绝孤儿申请单；审核写路径加数据库行锁，杜绝审批 TOCTOU 竞态。
  • 智能体配置副本一键分享：支持将个人调试好的智能体通过 JSON 快照发副本给同事，接收方一键克隆为个人专属智能体；7 天惰性过期，受创建权限管控；外部引擎（RAGFlow/OpenClaw）实例自动禁用分享。
  • 提示词工坊按维护者隔离：提示词工坊按维护者隔离，敏感系统提示词仅管理员可见可改，封堵越权查看与修改漏洞。

02 · 多部门多层级组织架构与数据权限治理

全面升级多租户企业级组织架构体系：

  • 全新部门管理模块：提供无限层级树形管理视图，采用 org_path 路径编码架构，支持主部门排序校准、成员列表中就地编辑用户与子树操作智能收敛。
  • 第三方同步与 AI 部门名注入：打通 LDAP / 钉钉同步部门归属；智能体对话上下文自动注入可读部门名，告别大模型回答「/1/」代码的机械感。
  • 角色成员就地抽屉管理：角色管理支持直接在右侧抽屉内就地查看并维护所属成员；修复角色成员数虚高与脏数据，支持按成员数排序。

03 · 动态菜单全面入库与系统权限三层解耦

打破前端路由与菜单绑死的历史框架，带来极致的动态定制体验：

  • 菜单管理全入库配置：全站左侧菜单沉淀入库（sys_menus），支持后台动态调整菜单层级、排序、图标以及外部网页链接。
  • 界面与功能权限彻底解耦：界面菜单显示（menu:*）与功能点控制（element:*）彻底分离，权限树升级为三层可视化折叠树，角色权限标色区分。
  • 独立权限管控与桌面端标识：数据源管理与 MCP 工具集拆分为独立功能权限；支持标注「仅桌面端可见」菜单并支持一键筛选视图。

04 · 个人资产协同共享生态（MCP 与技能分享）

赋能团队内开发者与知识专家的无缝协作：

  • 个人 MCP 与技能直享同事：个人调试的 MCP 工具集与高级公共技能支持一键分享给团队同事，接收方一键安装复用，降低重复配置成本。
  • 技能包体量大幅放宽：技能包上传上限提升至 100MB，解压改走异步线程池，文件上限放宽至 20,000 个，轻松容纳复杂代码工程技能。
  • 内置 Echo 回显测试与平滑解绑：个人 MCP 新增本地 Echo 测试服务，离线快速验证 MCP 通路；账号删除时级联解除作者绑定，杜绝资产悬空。

05 · 会话流单写入方闭环与移动端细节打磨

彻底攻克刷新/切页后流式恢复内容重复的历史难题：

  • 确立「单写入方」模型（Single Writer）：实时流在途时续显轮询让位；首次拉取一律清空累加字段全量重建，彻底杜绝重叠正文被双写的现象。
  • 令牌与代次丢弃机制：引入写入方令牌与代次自增，切会话或让位时在途旧轮询结果整批丢弃，不动游标防止正文回退。
  • 二次挂起状态保护：外部执行恢复流若再次挂起，状态准确保留为 pending，避免卡片提前完成导致提交区消失、后端超时挂起。
  • 移动端滚动条与 Token 露出：AI 消息操作栏右侧露出「圆柱图标 + 50.6K tok」，彻底根治双向滚动撑出的纵向固定灰条。

  • 工作区批量操作与邮件附件：工作区支持文件全选批量删除与任意二进制下载；send_email 原生支持工作区文件附件。

🐛 重点缺陷修复 (Bug Fixes)

🤖 智能体与生命周期

· 待审版本被误删导致孤儿申请单：待审状态的版本加入保护锁禁止物理删除，防止对应申请单悬空及智能体永久处于不可编辑态。

· 智能体中心切换到分享视图白屏：修复分享视图数据结构与搜索框绑定冲突，分享面板保留检索过滤。

· 非管理员复制他人系统级智能体：统一归属判定，严格限制普通用户仅能查看自建智能体，禁止通过复制接口私自克隆系统智能体。

· 模型切换白名单误拦截：修复版本配置切换模型时校验逻辑遗漏当前生效模型的边界缺陷。

· 只读智能体配置异常引导错误：只读智能体出现工具失效等配置异常时，提示文案由修改按钮自动转为联系管理员。

🏢 组织架构与权限系统

· 权限树脏数据与残留关联：清理历史遗留的孤儿用户角色关联数据（V177/V78），修复成员数统计虚高。

· 角色搜索搜不到默认角色：业务角色搜索改走服务端精准过滤，修复前端分页下搜不到 default 角色的问题。

· 设置密码点击无响应：修复管理端为特定用户设置密码弹窗无法正常唤起的交互 bug。

· 部门路径编码写入旁路：封死组织架构快照的旁路更新入口，强制走主更新链路校验。

🌊 会话交互与恢复机制

· 会话恢复流重复回放前序内容：通过单写入方机制与代次丢弃策略，彻底解决刷新/切页面恢复时正文双显与思考叠加。

· 切会话历史侧栏卡在加载态：会话切换收尾动作全面转入后台异步处理，解决侧边栏快速连点时界面冻结在 loading 的卡死现象。

· 嵌入式会话 401 偶发报错：修复 EmbedChat 嵌入鉴权 Header 提取与跨域携带凭证，拉齐测试基线。

· @ 浮层挂载工作区文件失效：增强输入框 @ 文件面板解析逻辑，支持直接将工作空间文件挂载至当前轮对话上下文。

🛠️ 工具、MCP 与存储

· 对话历史长文本落库整行丢失：MySQL 消息历史表字段由 MEDIUMTEXT 扩容至 LONGTEXT（V184），支持超大体量代码与 Markdown 存储。

· MCP 远端已删除工具残留：对于远端已下线的 MCP 工具，提供一键清理能力，并改用平台标准 tooltip 明确说明原因与恢复路径。

· RAGFlow 异常响应解析失败：当上游 RAGFlow 返回非 JSON 格式报错（如 HTML 502/网关超时）时，提取诊断信息返回友好错误提示，杜绝 JSON 崩溃。

· 工作区下载格式白名单误拦：移除工作区文件下载的格式后缀白名单限制，任意合法二进制文件与 zip 均可原样安全下载。

📖 平滑升级指南 (Upgrade Guide)

遵循以下标准步骤即可平滑无缝升级至 v1.0.20.0。请务必注意：本版本新增 15 组数据库迁移必须执行。

方式一：源码拉取升级（开发与虚机部署）

# 1. 同步拉取主分支最新代码

git fetch origin && git checkout main && git pull origin main

# 2. 执行数据库结构平滑迁移 (MySQL / PG)

bash db-prod/apply-sql.sh # PG: bash db-prod-pg/apply-sql.sh

# 3. 更新依赖环境并启动本地服务

poetry install --no-root && ./dev.sh

方式二：Docker 容器化升级（生产环境推荐）

# 1. 执行数据库增量升级 (宿主或临时容器)

bash db-prod/apply-sql.sh # PG: bash db-prod-pg/apply-sql.sh

# 2. 导入官方 Release 镜像归档（x86_64 / ARM64 按架构选择）

docker load -i nanzi-ai-agent_1.0.20.0_linux-amd64_*.tar

docker load -i nanzi-ai-agent_1.0.20.0_linux-arm64_*.tar

# 3. 重启容器服务

cd docker && ./start-nanzi-ai-agent.sh

方式三：沙箱构建与运维 CLI（若启用沙箱）

bash sandbox/docker/build-docker-sandbox-image.sh
