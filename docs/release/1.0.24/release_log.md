# 🎉 NanZi AI Agent Platform v1.0.24.0 Release Notes

**GitHub Repository**: [RandyChen1985/nanzi-ai-agent-platform](https://github.com/RandyChen1985/nanzi-ai-agent-platform)

v1.0.24.0 版本是一次以 **凭据从一整段文本变成可拆字段的结构化凭据、平台长出文生图与图生图、管理员能把公告一次发给全员、工作区文件能生成可控的分享链接、定时任务表单从「填一堆字段」变成「说清这一件事」、子智能体的权限确认回到你面前** 为核心驱动，并第一次把 **前端类型错误清零、后端已知失败基线清零** 的版本。

本次变更范围自 `2920e9ad`（`1.0.23` tag 之后的首个提交，含）至 `472e6452`（含），共 **130 个提交**（其中非 Merge 提交 114 个），涉及 **455 个文件**、**73,017 行新增代码** 与 **3,732 行删除**。

> ⚠️ **升级注意**：本版 **2 项必须先做**、**3 项视环境处理**，按下面顺序过一遍即可。
>
> **🚨 必须先做（顺序不能错）**
>
> **1. 5 组数据库迁移跑完，再启动新代码**：MySQL `V218`~`V222`、PostgreSQL `V118`~`V122`，两套一一对应、不可跳号，覆盖群发记录、凭据值形态与字段路径、多值配法组标识、图像生成配置、文件分享。新代码会读这些新增的列与配置，迁移没跑完会直接报错。执行 `bash db-prod/apply-sql.sh`（MySQL）或 `bash db-prod-pg/apply-sql.sh`（PostgreSQL），脚本自带进度、断点续跑与结构校验。
>
> **2. 存量「多值凭据」配置需要在多值页重新保存一次**：本版给绑定加了「属于哪一次多值配置」的组标识，历史数据这一列为空。不重新保存也不报错，但界面仍会把一条「多字段共用同一份凭据」的配置显示成 N 条独立规则，改其中一行就会把整组悄悄拆散。打开该工具的参数设置、在多值页点一次保存即可。
>
> **🔧 视环境处理**
>
> **3. MCP 服务的命名规则变了，但存量不迁移**：新服务名是「私有/公开 + 用户编号」的短标识，只允许英文数字，长度从三十来个字符降到十来个，卡片上会显示创建人并支持按创建人搜索。历史名字不动、也不会被强制改，只有改名那一刻才校验——所以老环境升级后动作与之前完全一致。
>
> **4. 建议把「上下文摘录总量」从 2000 调到 3000**：摘录的单条配额改为跟随总量（总量 ÷ 8，下限 120 字符），此前单条写死 120 字符、长任务请求会被切在半句上。只调总量不调这个数也能跑，只是总量没放大时摘录条数会少约 15%。
>
> **5. 三件与部署形态有关的小事**：老环境点一次「创建内置测试 MCP」即可补齐第三个工具（发信），内网 SMTP 会被出站守卫拦截、需要另加白名单；前端类型门禁接在 CI（推主分支、开发分支与提 PR 时跑），部署脚本与镜像构建仍走原来的打包命令，没有接入类型检查；站内信按平台策略保留 30 天，群发公告同样适用，但每次群发的发送记录永久保留。

## 🚀 Key Features

### 1. 🔐 凭据中心：一条凭据拆成字段，谁用哪个字段说得清 (Structured Credentials)
*   **先说模板再填表**：29 个内置模板分 9 组——邮件、FTP、数据库、云存储、机器人、鉴权、证书、中间件、AI，选好模板逐项填，不用记 JSON 的键名；想自己组织就从空白开始，改成键值对表格逐行加字段（名、类型、值），敏感字段逐行勾选，随时能切回手写。
*   **一条凭据分给多个参数**：同一台服务器的地址、端口、账号、密码一次配好，分别绑给一个工具的四个参数，不必为每个参数各建一条凭据、也不必在每条里塞重复的值。
*   **绑定会说「取哪个字段」**：选完凭据还能指定只取某一个字段（嵌套路径也认）。取不到就直接报错告诉你缺哪个字段，绝不会把整段 JSON 原样注进参数让远端去报错。
*   **规则也能按字段值找人**：调用方传来的是一个邮箱、一个实例名时，规则可以拿它去比凭据里的某个字段，命中最贴合的那条；规则编辑器把「按字段匹配」与「让模型在候选里挑」并列摆出来，不再把后者藏成兜底选项。未命中时会说清「拿什么去找、跟什么比、候选几条」，入参没值会直接点出、敏感入参打码。
*   **看得懂、查得到、改得回来**：列表能看出这条是单值还是结构化，并给出「主机:端口 · 账号」这种只由非敏感字段拼成的摘要；使用记录按一次操作聚合（一次调用注入五个参数只占一行，可展开看明细）并带上会话入口；变更记录可按键词搜索、按动作筛选，凭据标识一键复制；轮换结构化凭据会带出原来的字段名与类型，不必凭记忆默写键名。

### 2. 🎨 图像生成：会画图，也算得清花了多少 (Image Generation)
*   **一句「画一张」就出图**：模型判断你要图时自行调用出图工具，图直接渲染在消息里并落盘成产物，不需要审批，也不用切到另一个页面。
*   **生成与改图两个入口**：传一张图再加一句要求就是改图，可附参考图；改图面板与对话共用同一份参数，手机上也能打开。分辨率第一格直接显示后端配置的默认尺寸并默认选中。
*   **出图期间有占位**：消息区先出现一条占位横幅，写着当前阶段、走了几秒，并按目标比例画一个虚线框；图落地时高度不跳版，长对话不会被顶得乱跑。
*   **张数、尺寸、用量都留痕**：每次出图的张数、尺寸、上游返回的 token 与耗时写进执行轨迹，也在消息的「用量」与调用明细里可见。这一块刻意不并入消息 token 与月度配额——混进去会让「界面显示的用量」和「实际扣的配额」变成两套算法。
*   **设置页管得住成本**：系统设置多了「图像」分组，地址、密钥、模型、允许的分辨率、超时、单次张数都在这里，还带一次「测试生成」；总开关默认关闭，关闭时工具根本不发给模型，开启后还要在每个智能体里勾一次。分辨率只从白名单里挑，避免接口对不认识的尺寸静默回退；模型选择器会把非图像模型置灰，选错不会等到出图那一刻才暴露。

### 3. 📣 群发与分享：一次通知到全员，一个链接给对的人 (Broadcast & Sharing)
*   **管理员能按人、按部门、按角色发公告**：三种范围取并集去重，只发给启用账号，部门自动含下级；入口在「系统诊断」里，仅管理员可见。
*   **发之前先看命中谁**：预览给出人数与抽样名单；真正发送时必须带上预览时的人数，人数变了会被拦下并要求重新预览——不会出现「预览 128 人、实际发 300 人」。
*   **群发有账可查、可重发**：每次群发的范围、标题、正文与条数都留一条记录，历史列表可回看正文；重发只是把表单填回去再预览一遍，仍然要你亲手点发送，不做绕过确认的直发通道。收件人那边，铃铛把这条显示成「公告」并标出发件人。
*   **文件能生成分享链接**：按类型在线预览（网页、图片、PDF、文本）而不必先下载，可设访问密码与有效期，预览次数与真正下载次数分开计数——「看了一眼」和「存走了」不是一回事。链接冻结的是路径、大小与内容指纹，源文件被改写后旧链接自动失效，不会出现「副本与原件各自漂移」。
*   **只分享你自己的工作区**：此前只要知道路径、文件又挂在公共目录下，就能把别人的文件分享出去；现在归属校验收到本人。公共目录里的文件想分享走「复制并分享」，一步拿到副本的分享框并跳到副本所在目录；出图、跑表产出的文件也能直接分享，不必先手动保存。工作区卡片还出了缩略图，产物文件名去掉了前面那串 UUID，画布顶栏收成「⋯」菜单、字号与行宽控件移到页签栏，把顶栏空间还给标题。

### 4. 🗓️ 定时任务：从「填一堆字段」到「说清这一件事」(Task Form Redesign)
*   **两栏改成一句人话**：「要做什么」必填、「输出有什么要求」选填，两栏各有常驻提示条说明分工；往必填栏里写了格式类要求时，会提示「这段像是输出要求」并支持一键搬过去，也可以选择忽略。
*   **第 2 栏给现成写法**：移动端列表、只要结论、不要图表、金额统一万元、只看华东区五个常用要求一点就追加，重复点不会重复写。
*   **整页按三组重排**：做什么 → 什么时候跑 → 结果发到哪，右侧多了一条随填随更新的摘要，把散在六个字段里的意图拼成一句话，并给出下一次运行时间、交付要求条数与通知渠道。
*   **先选模板再填空**：新建时先给五个业务模板（指标报表、阈值巡检、周期简报、失败盘点、外部巡检）与「从空白开始」，套用后字段预填但不锁死，需要替换的地方统一用方括号标出并提示你替换。
*   **该折叠的都折起来**：三组章节可整组收起、标题带语义图标；失败重试策略默认收起，收起时行内仍显示当前策略（重试几次、间隔多久，或默认不重试）；「接下来三次运行」直接给出具体时间，第一项标「下次」，不再只有一个看不懂的表达式。

### 5. 💬 多智能体协作：授权回到你面前，进度不再丢 (Agent Collaboration)
*   **子智能体请求权限时，确认卡发到主会话**：不再当作失败终止，而是暂停等你在卡片上点选；确认后自动唤回同一个子智能体接着上次的进度跑，不用重新委派一次。卡片上标出「来自某个子智能体」，过程日志也带着它的名字。
*   **授权范围收得很紧**：「允许这一次」只覆盖同一工具、同一参数的那一次调用，两分钟内有效；批准列目录不会顺手放行删除，给资产导出授权也不会放行另一个助手，无人值守场景一律不放行。
*   **删除类命令不再有假按钮**：「本会话总是允许」对这类命令已撤掉（此前点了也不生效，下次照样弹）；用「允许这一次」也不再陷入「点允许—又弹—再点」的死循环，卡片会说明这类命令每次都要确认。
*   **反问之后不再丢任务**：提问轮会带上「提问前任务进度」并写在问题之前，你答完后的回执里明确要求「继续完成提问前尚未完成的项」；即使中间发生过上下文压缩，进度也会作为当前轮的状态重新注入，不再只剩一句问句加一个选项。
*   **答完能看见它在想什么**：子智能体的思考默认折在委派卡里，不再和主回答抢位置，也不会挤掉结论。长时间线与长回复的渲染也做了合帧：思考按帧合并、正文按渲染帧合并，两万个文件的大目录计数从 93 毫秒降到 16 毫秒。

### 6. 🛠️ 工具链与工程门禁：该连的连上，该拦的拦住 (Tooling & Quality Gates)
*   **图像类 MCP 工具不再必然失败**：单个流式事件的体积上限从 1 MiB 放宽到 32 MiB，此前返回一张图就直接超限报错。
*   **连接断开能自己恢复**：一次调用失败后，全站相关工具会一直报「连接已关闭」、只能重启解决；现在能识别成链路断开、淘汰旧会话并重连。共享会话的建立与关闭也收到专属线程，不再出现收尾抛异常、连接泄漏，关闭也设了 30 秒上限、不再无限等待。
*   **MCP 服务名短了、也看得清是谁建的**：新名字是「私有/公开 + 用户编号」的短标识，只允许英文数字，长度从三十来个字符降到十来个；卡片上显示创建人并支持按创建人搜索。存量老名字不迁移，改名时才校验。
*   **每个工具能单独定超时**：MCP 工具卡片上有了工具级超时入口，不必为了一个慢工具把整个版本一起放大；工具勾选多了「已选 / 全部」切换与按业务分组过滤，工具分组默认折叠，超时卡片也能收起。
*   **质量门禁第一次真正生效**：前端类型错误从 153 条清到 0 条，没有用忽略注解糊过去——其中三处是类型检查一直掩盖着的真缺陷（上传失败时进度显示成无效数字、参数搜索框失焦就报错且下拉关不掉、「仅桌面」筛选挡不住排序入口）。同时新增 CI 类型门禁：推主分支、开发分支或提 PR 时有错即红。后端的「已知失败基线」也从 36 条压到 7 条、再清到 0 条，机制保留、清单为空；另有 10 条历史红测试被修掉（9 条断言锚点过期，1 条是真缺口：凭据取不到值时补了修复建议）。

## 🐛 Bug Fixes

### 调度、定时任务与 Cron
*   **套用模板后运行周期与表达式对不上**：模板回填的是表达式，人话控件没跟着同步，会出现「控件显示每天、实际是每周」。现在套用后两者一起更新。
*   **折叠了失败策略就不知道还生效吗**：收起后行内直接写明当前策略——失败重试几次、间隔多久，或者默认不重试。
*   **只知道有任务、不知道什么时候跑**：执行计划下面原本只有一句表达式，现在直接列出接下来三次的具体时间，第一项标「下次」。
*   **编辑已有任务却先进了模板页**：新建与编辑的弹窗状态会互相残留。现在编辑直接进表单，关闭时统一复位。

### 会话、时间线与交互
*   **「进行中的步骤跑到上面去了」**：工具卡片会被吸附到上一轮旁白下面，看起来顺序错乱。现在按后端事件序号稳定排序，工具卡不再挪位。
*   **长时间线越用越卡、长回答越输出越顿**：思考与正文各自按帧合并渲染，历史重放时相邻文本帧也做压缩，大目录的文件计数移出主线程。
*   **提问轮正文与卡片内容重复**：正文里又贴一遍问题与选项，任务清单还混进执行明细。现在正文拆成「任务进度」与「待你确认」两小节，清单不再进明细。
*   **编辑器发版后，停在旧页面点菜单没反应**：前端资源已换、页面还是旧的，点菜单报找不到模块，只能手动刷新。现在检测到后自动刷新一次，仍失败就给一张明确的提示卡。
*   **被中断的工具结果显示成一串内部标记**：界面上出现的是框架内部的错误标签。现在显示「本轮已取消，工具未返回结果」。
*   **子智能体的思考被当成委派卡片**：委派卡提前变绿、思考一条都看不到。现在思考归位到委派卡内并默认折叠。
*   **浏览器提前关闭时刷出两条服务器错误**：每次关页面都记两条堆栈，把真故障埋掉。现在只记一条无堆栈的告警。

### 平台、权限与登录
*   **批量绑定凭据能绕过权限**：批量接口对全局层绑定的校验比单条松，非管理员可以把公用凭据绑成全局规则。现在与单条一致，非管理员一律拒绝。
*   **知道路径就能分享别人的文件**：归属校验只查到公共父目录就放行。现在只允许分享本人工作区里的文件。
*   **管理员浏览他人文件时，「分享」点下去才报错**：现在直接置灰，不再让人点了才知道不行。
*   **凭据流水里一串英文原因码**：与报错弹窗里的中文对不上，用户不知道该补什么。现在两边逐字一致，并把「拿什么去找、跟什么比、候选几条」写清楚。
*   **上传失败时进度显示成无效数字**：类型检查一直掩盖着这类分支，失败态下进度被算成空值。现在显示明确的失败状态。
*   **同一处参数配置改了一行，其余几条静默失效**：一条规则未命中就直接失败、不回退到同层的固定绑定，界面也没标出压制关系。现在按程度标注，一眼能看出哪条被哪条压住。

### 工具、沙箱与嵌入
*   **MCP 调一次失败，之后所有相关工具都报连接已关闭**：旧会话被当成活的反复复用。现在识别为传输断开并淘汰缓存会话，下一次自动重连。
*   **凭据提供的 Token 注入后仍然 401**：认证方案前缀被当成普通值一起替换掉了。现在缺方案时自动补全，远端要求的格式保持原样。
*   **脚本工具读环境变量永远是空、却报成功**：取消费方标识时读了一个配置里根本没有的项，第一道判断就返回了。现在能真正注入。
*   **工具一个请求头都没配置时，凭据注入整段被跳过**：界面上写着「来自凭据」，请求里却没有这个头。现在照常注入。
*   **改完 API 类工具，智能体在缓存期内看不到**：现在改动即失效缓存，流式调用的审计也补上了出参。
*   **上传可以绕过文件数上限**：单次上传有上限，但循环上传单个文件、反复解包能无限累计。现在统一按目录累计（默认 20 万个），各入口口径一致。
*   **多表查询可能把数据库打爆**：隐式逗号连接在没有关联条件时会生成笛卡尔积。现在静态校验会拦下这类语句并提示风险，带等值条件的传统写法仍然放行。
*   **内置测试服务的发信工具一直是模拟的**：现在支持真实连通验证与真实发信（默认仍是模拟），老环境再点一次创建即可补齐第三个工具。

## 🗄️ 数据库迁移清单 (Database Migrations)

本版新增 **5 组**迁移，MySQL 与 PostgreSQL 一一对应、**按版本号顺序执行即可**：

| 版本号 | 变更内容 | 迁移文件 |
|---|---|---|
| `V218` / `V118` | 新增管理员群发的发送记录表：每次群发的范围、标题、正文快照与实际条数；只存范围不存最终名单，重发时重新预览 | `V218-create-portal-broadcast-records.sql`<br>`V118-create-portal-broadcast-records.sql` |
| `V219` / `V119` | 凭据支持结构化值：值形态、模板标识、列表摘要三类描述列，绑定表增加「取哪个字段」的字段路径；只加描述、不改存储与加密链路，存量默认单值、无需回填 | `V219-add-secret-value-format.sql`<br>`V119-add-secret-value-format.sql` |
| `V220` / `V120` | 绑定表增加「多值配法」组标识：区分「每个参数各配一次」与「一次保存、多个参数共用一份凭据」；存量为空即单值配法，重新保存一次即可补上 | `V220-add-secret-binding-group-id.sql`<br>`V120-add-secret-binding-group-id.sql` |
| `V221` / `V121` | 系统设置新增「图像」分组：总开关（默认关闭）、地址、密钥、模型、允许的分辨率白名单、超时、单次张数、风格前缀 | `V221-add-image-generation-configs.sql`<br>`V121-add-image-generation-configs.sql` |
| `V222` / `V122` | 新增工作区文件在线分享表：冻结路径、大小与内容指纹，含访问密码、失效时间、预览与下载分开计数；不复制文件本体 | `V222-create-ai-file-shares.sql`<br>`V122-create-ai-file-shares.sql` |

**执行方式**：

```bash
bash db-prod/apply-sql.sh      # MySQL
bash db-prod-pg/apply-sql.sh   # PostgreSQL
```

两个脚本都带进度显示、断点续跑与执行后的结构校验，重复执行会跳过已应用的版本。

> 本版 **无预留编号**，5 组全部为实际新增，按序执行即可；两套脚本不可混用。
