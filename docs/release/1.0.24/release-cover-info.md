### 版本二：极客硬核版（技术社区/群发）
> NanZi v1.0.24.0 重磅发布：凭据值升级为「单值 / 结构化」双形态，29 个业务模板 + 键值对编辑器，绑定新增字段路径，注入侧按远端 schema 自动做数字与布尔转换，取不到字段直接报错而非退回整段明文；绑定加「多值配法」组标识，把「一条规则映射 N 个字段」与「N 条独立规则」彻底分开；一次性授权令牌按「父会话::子代理 + 工具 + 参数指纹」隔离、120 秒 GETDEL 原子消费，删除保护不被会话授权穿透；单 SSE 事件上限 1 MiB → 32 MiB；前端类型 153 → 0 且首次接上 CI 门禁，后端已知失败基线 36 → 0！

### 版本三：企业安全与协同版（企业集成与管理）
> 企业级内容分发与密钥治理的一次合流：NanZi v1.0.24.0 让管理员第一次能把公告按人、按部门、按角色一次发给全员——预览先看命中谁、发送必须带上预览人数、人数变了拒发，每次群发留痕可回看可重发；工作区文件可以生成带密码与有效期的分享链接，冻结内容指纹、源文件改写即失效，预览与下载分开计数；凭据侧，一条凭据的字段可分给多个参数、规则可按凭据内字段值精确匹配、越权路径与半保存状态被逐条堵死；子智能体的工具授权收敛到主会话作用域，删除类命令不再有「总是允许」的假按钮。
