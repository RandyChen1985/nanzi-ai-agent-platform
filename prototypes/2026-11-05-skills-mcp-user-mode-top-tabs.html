我的技能 / 我的 MCP · 单 Tab 时把左侧导航提到顶部

普通用户进入 /dashboard/skills、/dashboard/mcp 时，顶部只有一个一级 Tab（「我的技能」/「我的 MCP」）， 下面却还挂着一条 200px 的左侧二级导航（我的技能 / 收到的分享 / 我的分享）——一个 Tab 撑起一整列，内容区白白少掉 200px。 这版原型把「只有一个一级 Tab」时的二级导航提到顶部，内容区全宽。

现状：一级 Tab 下再挂一条左侧栏

已采用方案 C：直接 3 个 tab（与「智能体中心」同款）

只有一个一级 Tab 时，那一行整行不出现，顶部直接是「我的技能 / 收到的分享 / 我的分享」三个圆角 tab， 选中态浅蓝底 + 蓝字（bg-primary/10 text-primary），内容区全宽。

  • 与「智能体中心」的「我的智能体 / 分享给我 / 我分享的」完全同一种视觉，不再自造第二套；
  • 没有页面标题，Tab 行本身就是页面标识；管理员多 Tab 时保持原样。

备选（未采用）：方案 A「标题 + 胶囊」、方案 B「一级 Tab + 胶囊行」。

只有一个一级 Tab 时，把它从「绿色下划线的 Tab」降级成左侧标题（保留图标与计数）， 二级导航用胶囊紧跟在右侧；内容区直接全宽。

  • 顶部只占一行，层级变成「页面标题 → 视图切换」，不再有「Tab 套 Tab」的错觉；
  • 「我的技能」重复出现一次（标题 + 胶囊），但一个是页面名、一个是视图，视觉上能分开；
  • 管理员（有多枚一级 Tab：平台技能 / 待审核 / 已发布）保持现状，不受影响。

备选方案 B：一级 Tab 保留，下面贴一行胶囊

不动现有 Tab 行，只在它下方加一条浅底的胶囊行，左侧栏隐藏。改动最小、层级最直白， 代价是顶部占两行（约 96px），内容区略矮。

  • 适合不想动现有 Tab 样式、只做「把左侧挪上去」的场景；
  • 移动端现在已经是胶囊形态（variant="chips"），方案 B 等于把窄屏样式推广到宽屏。

实现落点（两个页面同构）

  • 技能页：SkillPersonalMenu 已有 variant="aside" | "chips"，只需在「一级 Tab 数量 ≤ 1」时隐藏 aside、把 chips 从 md:hidden 容器里放出来；
  • MCP 页：McpPersonalMenu 同样两套；注意它现在宽屏下 aside 与 chips 同时显示（重复），顺手收掉；
  • 判定条件用「可见一级 Tab 数量」而不是 ui_mode：专业模式下无平台权限的账号同样只有一个 Tab，也适用同一形态。

保持不变

  • 路由、深链（?menu=received 之类）、计数徽标、搜索与排序逻辑都不动；
  • 「收到的分享 / 我的分享」的内容面板原样复用，只换导航容器；
  • 深色主题沿用现有变量，不新增颜色。
