调度白名单 sub_agent_call

限制本智能体可以委派的子智能体范围。不配置则维持默认，配置后名单外的智能体一律拒绝。

i
未配置 = 全部「已授权给你的系统智能体」；配置后 = 只从名单中调度。
你自己的智能体默认不可被委派，加入名单后才开通；系统智能体即使进名单，仍要校验你的 agent 授权。
已选 3 个智能体

清空调度白名单？

清空后本智能体将无法委派任何子智能体（工具仍保留，但每次调用都会被拒绝）。
如果只是想恢复默认范围，请改用「取消」并删除该配置项。

③ 规则 两类智能体的含义不同：系统级是收窄，自建是开通

1未配置（默认）

与现状完全一致，老智能体不受影响。

  • 系统级：全部已授权的可委派
  • 自建：一个都不可委派

2已配置（收窄 / 开通）

名单成为唯一入口，三重交集。

  • 系统级：收窄到名单 ∩ 已授权
  • 自建：开通为名单 ∩ 本人创建 ∩ 已启用

3运行时动态校验

配置保存后仍会逐次校验，不适用的静默排除。

  • 智能体被禁用 / 删除 / 转让 → 排除
  • 用户失去 agent:<id> 授权 → 排除
  • 缺少发布版本或资源绑定 → 排除
运行时错误文案（现在统一报 agent_not_found 并列出全部候选，排障时看不出卡在哪一层）
不在白名单
错误：智能体 report-writer 未被加入本智能体的委派名单。可在工具配置的「调度范围」中加入，或改用名单内智能体。
在白名单但无授权
错误：当前用户无权使用智能体 report-writer（缺少该智能体的访问授权），请联系管理员。
有权限但未就绪
错误：智能体 report-writer 尚未就绪，缺少可加载的发布版本或主类型所需的资源/工具。
