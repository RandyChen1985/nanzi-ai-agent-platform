36 项
sandbox_policy

安全沙箱执行策略。local 表示宿主机扩展进程内直接执行；docker 表示在自动构建的 Docker 容器内执行；k8s 表示在 Kubernetes 集群内动态拉起独立 Pod 执行；e2b 与 ssh 用于远程云端/主机执行。

docker（Docker 容器）
在自动构建的 Docker 容器内执行，工作区按用户隔离

切换策略后，沙箱 Bash / 文件工具在对应环境内执行。仅当策略为 docker 或 k8s 时展示下方沙箱实例运行态与运维管理入口。

当前 Docker 沙箱实例概览 unix:///var/run/docker.sock
sandbox_auto_warm

沙箱自动预热开关（docker/k8s 均生效）。开启时，在打开或新建会话时静默预热沙箱。

已关闭（禁用自动预热）
sandbox_idle_time

沙箱空闲自动回收时长（分钟，docker/k8s 共用）。默认 15 分钟。

分钟（会话仍持有引用时放宽至 4 倍 = 60 分钟）
sandbox_orphan_reconcile

沙箱孤儿对账开关（docker/k8s 均生效）。单副本保持开启；多副本需关闭（僵死终态仍自动清理）。

已开启（每 10 分钟对账清理 >30 分钟孤儿）
