聊天日志页 · UI/UX 问题诊断与重构收益

针对当前截图与 ChatLogs.vue 源码分析，在不丢弃任何审计能力的前提下，重点解决首屏挤压、套娃边框、状态中英混排、自动化规则霸屏与多轮排障跳转低效 6 大痛点。

首屏有效阅读区 ~78% ↑ 原先仅 ~43%
内容区嵌套边框 1 层 ↓ 原先 4 层套娃
多轮定位点击 1 次 轮次胶囊直达

1. 顶部「三层叠床架」挤压首屏阅读区

P0 核心
现状痛点
页面大标题栏（76px）+ 独立搜索白卡（64px）+ 折行后的双行详情头（78px）+ Tab 栏（42px），合计吃掉近 300px 高度，右侧对话正文只露半截。
优化方案
标题、计数、搜索框、快捷状态胶囊、高级筛选、刷新合并为 48px 单行融合工具条；详情区元信息与 Tab 融合，释放出 140px+ 黄金阅读视口。

2. 四层「套娃卡片」与蓝色视觉噪点

P0 核心
现状痛点
大白卡 → 轮次圆角卡 → 灰框用户提问 + 浅蓝底 AI 回复框，四层边距叠加；AI 回复里亮蓝 H1 标题 + 蓝底「渲染/源码」开关与主题蓝撞色抢焦点。
优化方案
拆除多余嵌套，改用宽幅无框白底文档流；提问用柔和左竖条区分，渲染/源码降噪为低存在感灰底分段，Markdown 标题改深墨层级，表格和长文一眼通透。

3. 状态中英混排 & 自动化前缀霸屏

P0 核心
现状痛点
cancelled 直接渲染成全大写英文 CANCELLED，旁边却是中文「成功」；TaskCenter 任务列表被 【🌐 TaskCenter 自动化全局执行规则】... 填满，看不到任务本身。
优化方案
统一全中文状态字典（成功 / 异常 / 已取消）配轻量语义色点；自动识别系统前缀提炼为 「定时任务」微标签 + 真实任务标题，并提供「仅人工」一键过滤。

4. 详情头部信息无主次 & 操作按钮掉行

P1 体验
现状痛点
把时间戳当主标题，6 个边框胶囊一字排开；窄屏折行把「导出会话」按钮挤到第二行左侧，和 3600ms 8635d42e… 混排，右侧留大片空白。
优化方案
首行左侧放会话主题 + 状态徽章，右侧固定操作区（带标签可复制 Trace ID + 导出 Markdown + 折叠边栏）；元信息去胶囊化，以 · 轻量串联。

5. 多轮定位与轨迹排查链路割裂

P1 效率
现状痛点
11 轮对话只能靠滚轮翻找；每轮不知道用了几个工具；轨迹页签所有 JSON 黑框全展开，慢步骤与报错步骤淹没在瀑布流里。
优化方案
新增轮次快捷定位胶囊条（带异常红点与耗时）；每轮展示工具调用摘要胶囊；轨迹页升级为耗时占比条 + 可折叠步骤（报错步自动高亮展开）。

6. 列表项低频按钮常驻 & 宽内容查看受限

P1 细节
现状痛点
每条会话右下角常驻下载图标增加视觉噪点；左侧 360px 列表不可收起，AI 输出宽表格或长代码块时出现横向滚动条。
优化方案
列表下载按钮改为 Hover / 选中显现；详情左上角提供一键「折叠左侧会话栏」，瞬间切入沉浸宽屏阅读模式。
方案选择 核心特点 适合场景 改动成本
方案 A · 精炼文档流（推荐） 保留熟悉的左右双栏结构，通过单行工具条、去套娃排版、轮次跳转条、可折叠轨迹瀑布全面升级视觉与效率。 日常运营审阅 + 常规排障，兼顾小屏（1280px）与大屏，零学习成本。 纯前端单文件重构，0 后端改动
方案 B · 对话×轨迹同屏对照 在方案 A 基础上，将「轨迹」改为右侧常驻联动检查器，点击任意轮次立即同屏查看工具入参、耗时与报错。 重度排障 / Prompt 调优 / 1440px+ 宽屏显示器（1280px 以下建议自动折叠为抽屉）。 纯前端重构，略增宽屏响应式逻辑
