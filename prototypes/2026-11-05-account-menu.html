设计说明

为什么是「点头像弹菜单」

  • 头像在左下角、位置固定，用户已经习惯点它看「我是谁 / 我能改什么」，这是唯一不需要解释的位置。
  • 现在从专业模式切用户模式要「头像 → 个人中心 → 界面偏好 → 点用户模式」四步；放进菜单后一步，且切换后立刻看到界面变化。
  • 用户模式侧栏的「更多 → 切换到专业模式」与这里形成对称：两边都在自己最顺手的角落，随时可逆。

和参考图的取舍

  • 保留：头部用户块、分组、分隔线、右侧 hint / chevron、底部红色退出。
  • 替换：参考图的「套餐 / 积分 / 升级 / 购买」占视觉重心，本平台没有计费，换成「界面模式」两枚胶囊——这是用户当前真正会点的东西。
  • 去掉：早安问候、成长计划、邀约、检查更新（本平台没有对应功能，不画假入口）。

交互与可达性

  • 点击头像开/关；点击外部或 Esc 关闭；打开时焦点进入菜单，关闭后回到头像。
  • role="menu" + 每项 role="menuitem"，上下键移动、回车执行（落地时用现有 focus trap 或原生按钮 + 方向键）。
  • 模式胶囊 aria-pressed 表达当前态，切换后 toast 提示并跳转到对应首页。
  • 移动端：浮层改底部抽屉（bottom sheet），宽度撑满、圆角只保留上方，避免 320px 侧栏里浮层被裁。

落地改动点

  • 新建 frontend/src/components/AccountMenu.vue：接收 visible / user / mode / theme，emit close / switch-mode / set-theme / navigate / logout。
  • Dashboard.vue：openUserInfo 改为切换 accountMenuOpen；把 handleUserModeSwitchMode 复用给菜单。
  • UserModeSidebar.vue：头像点击 emit open-account-menu，由 Dashboard 统一渲染（收起态也能用）。
  • 模式切换复用 useUiMode().setUiMode，主题复用 useAppTheme().setTheme，不新增接口。
待确认：① 切模式后是否自动跳首页（建议跳：用户模式 → 聊天页，专业模式 → 概览）；② 是否把「通知设置」换成「消息中心」直达；③ 关于页要不要加「更新日志」。
